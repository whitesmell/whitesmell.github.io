本文讲述了 Vikas Paruchuri 如何在一年内从零学习深度学习，并使用深度学习技术开发出多个实用工具的经历。Paruchuri分享了学习深度学习的有效方法，包括阅读书籍、论文、参加社区讨论，以及动手实践等。此外，Paruchuri还强调了开源的重要性，并建议读者在学习过程中尝试开源项目。

Vikas Paruchuri 是一位位于 Oakland 的开发者，创办了教育公司，赢得了机器学习竞赛，并担任过美国外交官。他的项目 Marker 是一个将 PDF、EPUB 和 MOBI 文件转换为 Markdown 的工具，比 nougat 快 10 倍，对大多数文档的准确性更高。Marker 的工作原理是一个深度学习模型的流水线，它通过 LLM 前向传递处理方程式块，从而更快且具有低幻觉风险。

我经营教育公司 Dataquest 八年后，于去年萌生了重返开发领域的想法。深度学习一直吸引着我，但由于缺乏了解，我决定开始学习之旅。

自那时起，我训练了数十个模型 (包括一些开源领域的先进模型)，构建了两个在 Github 上获得 5000 多颗星的库，并最近接受了 answer.ai 研究实验室的职位邀请。

本文将分享我的深度学习学习经验，希望对读者有所启发。


我的背景

我的专业背景并非计算机科学，大学主修美国历史，而且还挂科很多。

2012 年，我曾接触过机器学习和 Python，但当时认为深度学习过于复杂，无法掌握。部分原因是我主要通过参加 Kaggle 比赛来学习，这种方式虽然可以快速提升技能，但也容易导致基础知识的缺失，例如对算法数学原理的理解不足。

早期的深度学习非常注重数学，这让我望而却步。十年后的今天，我终于证明了自己可以理解深度学习，但学习方法的选择至关重要。最初，我采用自上而下的方式，将模型组合在一起却并不了解其工作原理，最终陷入困境。


有用的技能

我在学习深度学习时已经具备了一些有用的技能。首先是强大的 Python 编程能力。尽管有一些替代方案出现，Python 仍然是 AI 领域的通用语言。因此，想要进入 AI 领域，首先要精通编程。

其次是数据处理能力。无论 AI 发展到哪个阶段，数据清理工作始终占据了我 70% 以上的时间。除非进行纯理论研究或处理玩具问题，否则数据处理技能必不可少。

最后是一种被称为“实用主义”的能力。深度学习领域存在许多“兔子洞”，例如“什么是完美的基准模型？”或“如果我删除 sigmoid 函数会怎样？”。有些问题值得深入探究，但大多数只会浪费时间。因此，能够判断何时深入研究，何时采用快速简单的解决方案至关重要。


书本学习

这一次，我决定从基础知识开始，自下而上地学习。我选择了《深度学习》这本书，尽管出版时间较早，但仍然是极佳的学习资源。阅读时要放慢速度，仔细查阅不熟悉的术语和数学知识，必要时可以画图或编写代码辅助理解。如果数学基础薄弱，可以参考《机器学习数学》这本书。此外，fast.ai 和 Karpathy 的视频课程也是不错的选择。

尽管像 CNN 或 RNN 这样的架构在 Transformer 大行其道的今天可能显得有些过时，但 CNN 仍然广泛应用，而 RNN 也在焕发新生。

完成本书前两部分 (第三部分可以跳过) 后，读者应该能够使用 NumPy 编写任何主要的 神经网络架构 (包括前向和后向传递)。

在学习过程中教授他人是一个巩固知识的好方法。我在阅读《深度学习》的同时，开始整理一门名为“从零到 GPT”的课程。教学迫使我深入理解并清晰地表达概念，从而形成良性循环。


论文阅读

《深度学习》这本书涵盖了 2015 年以前的深度学习知识。之后，我阅读了一些 2015-2022 年间具有奠基意义的深度学习论文，并在 PyTorch 中进行了实现。Google Colab 可以提供免费或廉价的 GPU 资源，Weights and Biases 则可以用于跟踪训练过程。

微调和 Discord

目前，训练模型最简单的入门方式是微调基准模型。Huggingface transformers 库提供了许多预训练模型，并且使用 PyTorch 框架，非常适合微调任务。

一些 Discord 社区，例如 Nous Research 和 EleutherAI，是讨论最新模型和论文的理想场所。加入这些社区，了解最先进的技术，并尝试进行一些微调实验。

最简单的微调方法是选择一个小模型 (参数量小于 7B)，并使用 LoRA 技术进行微调。可以使用 Google Colab 或 Lambda Labs 等平台获取 GPU 资源。

我希望训练模型来更好地编写代码，因此我整理了一些数据集，并在 StackOverflow 等平台的数据上微调了几个不同的基准模型。这帮助我理解了模型架构、数据、计算和输出之间的关系。然而，微调是一个竞争激烈的领域，由于最先进的技术日新月异，很难产生持久的影响。

问题发现

在微调模型的过程中，我意识到一些高质量的数据以教科书的形式存在于 PDF 文件中。我尝试了两种方法来解决这个问题：生成合成数据和从 PDF 文件中提取数据并将其转换成训练数据 (markdown 格式)。虽然现有的 nougat 方法在许多情况下有效，但速度慢且成本高。

因此，我决定开发一种更高效的方法，即利用 PDF 文件中已有的数据 (避免使用 OCR)，并仅在必要时使用模型。我将多个模型和启发式方法结合在一起，开发了 marker 工具，其速度比 nougat 快 10 倍，支持所有语言，并且通常更准确。

marker 项目激发了我解决更多问题的兴趣，我还训练了方程式到 LaTeX 的模型、文本检测模型、与 Google Cloud 竞争的 OCR 模型，以及布局模型。

对于所有这些模型，我都采用了现有的架构，并对其层、损失函数和其他元素进行了修改，然后生成或找到了合适的数据集。例如，对于 OCR 模型，我从 Donut 架构开始，添加了 GQA、MoE 层、UTF-16 解码 (每个字符 1-2 个标记)，并调整了一些模型形状。

由于 OCR 模型通常较小 (参数量小于 3 亿)，我能够在 4 个 A6000 GPU 上训练所有这些模型，甚至可能只需 2 个 A6000 GPU 就能完成。

这说明了以下三点：

理解基础知识对于训练好的模型至关重要。

找到有趣的问题并解决它们是产生影响的最佳方式。

不需要大量 GPU 资源。

在 AI 领域，即使是相对的局外人，也可以在许多细分领域产生重大影响。


开源

我将所有 AI 项目开源。相对于其重要性而言，数据栈是 AI 领域投资不足的领域。我坚信，高质量训练数据的广泛传播可以降低 1-2 家机构垄断优秀模型的风险。

开源还有助于提高知名度，这也引出了故事的最后一部分。


获得研究工作

我曾经考虑过围绕开源工具建立一家公司，并没有求职的打算。但当 Jeremy 联系 answer.ai 时，我认为这是一个不容错过的机会。与优秀人才共事、产生积极影响并学习新知识的机会非常难得。

我的开源工作直接促成了这个工作机会，因为它不仅提高了我的知名度，还显著提升了我的技能。我希望读者在学习过程中也能尝试开源项目。
