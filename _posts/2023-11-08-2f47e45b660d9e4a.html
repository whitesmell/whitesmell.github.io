OpenAI于11月7日举行了其首届开发者大会,发布了一系列新的AI产品和功能升级:

GPT-4 Turbo

GPT-4 Turbo是OpenAI推出的GPT-4模型的升级版本,相比GPT-4原模型有显著的改进:

1. 提供更长的上下文长度(128,000个标记,相当于300页书的文本量),是GPT-4原始模型的16倍。这对许多需要长文上下文的任务非常有帮助。并且在长上下文条件下,GPT-4 Turbo的生成质量也有提高。

2. 提供了更多的输出控制能力。比如新增了JSON格式响应的保证,开发者调用API时返回确定为合法JSON格式,大大简化了与API的交互。另外,函数调用能力也得到增强,可以同时调用多个函数了。此外,还新增了“可复制输出”功能,可以通过指定随机数种子的方式,让模型每次给定同一个提示时生成同样的输出,增加了可控性。

3. 知识库更新到了2023年4月,解决了用户反馈GPT知识库时效性不足的问题。OpenAI表示会持续更新知识库,保证知识切合时代。

4. 将新模态能力如视觉、语音合成集成到模型中,支持多模态交互。

5. 大幅降低了模型调用价格,Prompt token降为原来的1/3,Completion token降为原来的1/2。综合下来对大多数客户而言调用价格降低了75%以上。这一定程度上缓解了开发者反馈GPT-4价格过高的问题。

6. OpenAI表示他们接下来会继续提升GPT-4 Turbo的响应速度,这也是开发者关心的另一大问题。

GPT-3.5 Turbo 升级

GPT-3.5是OpenAI早前推出的中等规模的语言模型,相比GPT-3原始模型有显著的质量提升,但调用价格依然较高。

1. 将Fine-tuning个性化调整功能拓展到了GPT-3.5的16k版本(指可以处理1.6万个token的上下文长度)。原先只在GPT-3.5的4k版本上支持Fine-tuning。拓展到16k版本意味着开发者可以用更长的prompt来个性化调教这个模型,提升其在自己任务场景上的表现。

2. 大幅降低了GPT-3.5 Turbo的价格。具体来说,输入的Prompt Token降价3倍,输出的Completion Token降价2倍。这使得GPT-3.5 Turbo 16k版本的价格不仅低于原GPT-3.5的价格,甚至比原先GPT-3.5的4k版本还要便宜,极大减轻了开发者的使用成本。

Assistant API

1. Assistant API可以更轻松地为App构建智能助手或代理人功能。开发者只需提供一个名字、初始指令、要使用的模型(如GPT-4 Turbo)等基本信息,就可以快速创建一个助手。

2. API提供了会话线程(Conversation Threads)功能。即为每个用户保存一个持久化的对话线程,而不需要开发者自己构建这种状态管理。这大大简化了构建对话式助手所需的技术难度。

3. 提供内置的检索(Retrieval)功能。助手可以读取外部文档、数据库的知识,融入到对话中。不再需要开发者自己搭建知识库。

4. 集成了代码解释器(Codex)。助手可以根据指令直接调用API,编写和执行代码,无需开发者自己实现这种能力。

5. 支持调用OpenAI新发布的视觉、语音等API能力。可以让助手具备看图说话、语音交互的多模态能力。

6. 助手可以保持长期记忆。即可以记住之前对话内容,而不会随着API调用被重置状态。

7. 开发者仍可以查看助手的工作流程、访问对话历史,对其行为保持一定的透明度。

8. Assistant API目前处于测试阶段,后续会进一步开放更多可自定义的选项。

这套API极大地降低了构建智能助手的技术门槛,使任何开发者都可以为他们的App轻松添加人工智能的交互体验。相信会触发新的应用场景和奇思妙想。

GPTS，可自定义的ChatGPT

1. 用户现在可以通过聊天界面,使用自然语言对话来创建自定义的GPT,赋予它特定的知识、交互逻辑和能力。

2. 创建界面非常简单直观。用户只需要告诉GPT你想要它做什么,它就会自动生成一份详细的配置文档,并与用户互动完成定制。

3. 用户可以为GPT上传外部文件,丰富其知识源。比如上传自己讲课的文字资料,GPT就可以基于这些内容给出建议。

4. 用户可以配置GPT的回复风格、应具备的交互能力等。GPT会自动在预览界面生成示例,用户可以快速迭代。

5. 定制完成后,用户可以将GPT设置为私密状态,或者生成一个分享链接,公开与他人使用。

6. OpenAI正在测试GPT商店的功能。用户可以在商店中发布自己的GPT,如果流行度高、备受好评,可以获得收益分成。

7. 企业用户可以在ChatGPT企业版中创建内部使用的GPT。

这种可定制化允许普通用户也参与创造AI内容,使ChatGPT对不同用户和场景提供更个性化的服务。相信会涌现出各种有趣的GPT扩展应用。
