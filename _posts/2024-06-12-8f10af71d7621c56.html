Ferret：Apple Intelligence 的核心，让手机 UI“无所不知，无所不能”

近年来，多模态大语言模型 (MLLM) 的进步有目共睹，但这些通用模型在理解和交互用户界面 (UI) 方面却常常力不从心。想象一下，如果你的手机能够真正理解屏幕上的内容，并根据你的需求进行操作，那将是怎样一种体验？Apple 发布的 Ferret 模型，正是为了实现这一目标而生！它专为增强移动 UI 屏幕理解能力而设计，具备强大的 referring、grounding 和推理能力，能够识别屏幕上的图标、文本框、按钮等 UI 元素，并理解它们之间的空间关系和功能含义，从而像人类一样感知和操作 UI 界面。

Apple 在 Intelligence 发布会上宣布了这一激动人心的消息，预示着 AI 技术将全面融入 iOS 操作系统。Ferret 作为其中最为核心的模型之一，将彻底革新我们与移动设备的交互方式，让 UI 界面变得“无所不知，无所不能”。正如Andrej Karpathy所说：

“我真的非常喜欢 Apple Intelligence！... ... 我们正快速步入一个只需对着手机说话，它就能理解并执行指令的时代。这真是超级令人兴奋，作为一名用户，我非常期待！”

Ferret：破解 UI 理解难题

图1：Ferret 模型架构图

不同于专注于自然图像的传统 MLLM（如 Shikra [1]、Kosmos2 [2] 等），Ferret 专为理解移动 UI 屏幕而设计，具备 referring、grounding 和推理能力。Ferret 模型的优势在于：

  • • 专门针对 UI 设计: 不同于以往需要外部检测模块或屏幕视图文件的 MLLM，Ferret 能够直接将原始屏幕像素作为模型输入，无需依赖其他模块或文件，更适合移动 UI 场景。

  • • 精细理解: Ferret 不仅能识别 UI 元素，还能理解其空间关系、功能含义，实现更精细的理解，例如区分不同类型的图标、识别被遮挡的 UI 元素等等。

  • • 推理能力: Ferret 能够根据 UI 元素之间的关系和功能，进行推理，例如推断某个按钮的功能、预测用户的下一步操作等等。

Ferret 如何工作？

Ferret 模型的强大之处源于其独特的架构设计（如图 1 所示）。它在 Ferret 模型的基础上，整合了“任意分辨率” (anyres) 技术，可以灵活适应各种屏幕比例，并放大细节，提取更丰富的视觉特征。具体来说，Ferret 模型的工作流程如下：

  1. 1. 图像编码: 首先，Ferret 使用预训练的图像编码器（例如 CLIP-ViT-L/14 [3]）对 UI 屏幕截图进行编码，提取图像特征。

  2. 2. 区域特征提取: 为了更好地处理 UI 屏幕中形状各异、大小不一的 UI 元素，Ferret 采用了一种混合区域表示方法。

    • • 它使用空间感知视觉采样器，根据文本指令，精确定位 UI 屏幕上的目标区域或元素，并将该区域的图像特征提取出来。

    • • 为了解决 UI 屏幕比例问题，Ferret 集成了“任意分辨率” (anyres) 技术，可以灵活地将屏幕划分为多个子图像，分别进行编码，然后再将这些子图像的特征整合起来，从而保留更丰富的视觉信息，提升对 UI 元素的识别精度，尤其对于小尺寸 UI 元素，效果提升显著。

  3. 3. 语义理解: Ferret 使用 Transformer 解码器对图像特征和文本指令进行联合编码，理解 UI 元素的语义信息，并进行推理。

  4. 4. 输出: 最后，Ferret 根据任务需求，输出相应的文本或 bounding box。

海量数据，精雕细琢

为了训练 Ferret 模型，Apple 构建了涵盖多种粒度、覆盖基本语义和空间任务以及高级推理任务的训练数据集（如表 1 所示）。

表1：移动 UI 屏幕和训练数据统计

  • • 基本 UI 任务数据集: 该数据集包含大量从实际应用中收集的 iPhone 和 Android UI 屏幕截图，并利用模板生成的方式，为每个屏幕标注了丰富的语义和空间信息，涵盖了 7 种基本 UI 任务，例如图标识别、文本查找、控件列等等。

  • • 高级 UI 任务数据集: 为了进一步提升模型的推理能力，Apple 利用 GPT-4 生成了包含详细描述、感知对话、交互对话和功能推断等任务的数据集。

这些精心设计的数据集，为 Ferret 模型提供了充足的学习材料，使其能够掌握 UI 界面中的各种模式和规律。

性能测试：Ferret 表现亮眼

为了评估 Ferret 的性能，Apple 在 Spotlight [4] 基准测试的基础上，构建了一个更全面的测试基准，包含 14 种不同的移动 UI 任务，涵盖了 referring 和 grounding 两种类型，并与其他 UI 理解模型（例如 CogAgent [5]、Fuyu [6] 和 GPT-4V 等）进行了比较。

表2：Ferret-UI 和基线模型的结果

实验结果表明，Ferret 在各项任务中均取得了优异的成绩，尤其是在基本 UI 任务上，Ferret 的性能明显优于 GPT-4V，展现出其在 UI 理解领域的强大实力。

Ferret：Apple Intelligence 的核心引擎

Ferret 模型的推出，是 Apple Intelligence 发展历程中的重要里程碑，它将与其他 AI 技术协同工作，打造更加智能、无缝、主动的 iOS 体验。Apple Intelligence 的几大主题与 Ferret 的能力相辅相成：

  • • 多模态输入输出，无缝衔接: Ferret 的 Multimodal I/O 能力使其可以处理文本、音频、图像、视频等多种形式的信息输入和输出，并与其他 AI 模块无缝衔接，为用户提供更便捷的操作方式。例如，你可以通过语音指令让 Ferret 帮你查找照片、发送信息，甚至预订餐厅。

  • • 代理执行，智能协同: Ferret 的代理性 (Agentic) 使其能够充当用户的智能代理，根据用户的指令，协调操作系统和应用程序的各个部分，完成复杂的任务。例如，你可以让 Ferret 帮你安排行程、预订酒店，它会自动帮你完成所有操作。

  • • 主动建议，先你所想: 更令人惊叹的是，Ferret 还具备主动性 (Initiative)。它能够根据你当前的操作和上下文，预测你的下一步操作，并主动提供建议或解决方案。例如，当你打开地图应用时，Ferret 可能会主动推荐你常去的餐厅；当你编辑邮件时，它可能会根据邮件内容，推荐你添加附件。

  • • 分层委派，高效协作: Apple Intelligence 强调将尽可能多的智能转移到设备上，但允许选择性地将工作分派到云端，Ferret 可以根据任务的复杂程度和设备的性能，动态地选择在本地或云端执行任务，保证效率和性能的平衡。

  • • 模块化，灵活扩展: Ferret 模型采用模块化设计，可以灵活地与其他 AI 模型组合使用，例如 ChatGPT 等，不断扩展 Apple Intelligence 的功能和应用场景。

Ferret：未来已来

Ferret 模型的推出，预示着移动设备将迎来更加智能、人性化的未来。它不仅将改变我们使用手机的方式，还将推动 AI 技术在更广泛的领域落地应用。

在移动办公、智能家居、辅助技术等领域，Ferret 都将大放异彩，为用户带来前所未有的智能体验。未来，我们将可以用更自然、更直观的方式与设备进行交互，而设备也将变得更加智能、更加懂我们，成为我们生活中不可或缺的伙伴。
