昨日，OpenAI发布重磅消息，宣布GPT-3.5 Turbo模型支持用户自定义微调(fine-tuning)。这意味着企业和开发者可以使用自己的数据集训练定制的GPT-3.5 Turbo模型，从而在特定的任务上获得更好的表现。

随着GPT-3系列模型的快速发展，语言模型已经能够展现接近人类水平的语言理解和生成能力。但是这些通用预训练模型往往无法完全满足不同行业和企业的具体需求。因此微调成为一个重要手段，可以帮助调整模型使其更加适应特定的下游任务，比如对话、文本摘要、语音识别等。

OpenAI此次开放GPT-3.5 Turbo微调访问权限，将进一步释放其强大能力，使企业能根据自身场景获得定制化的AI解决方案。、

GPT-3.5 Turbo微调功能开放，GPT-4的微调在路上

GPT-3.5 Turbo是OpenAI于今年早些时候推出的新模型，被设计为专门用于非对话类任务，相比GPT-3拥有更强的理解和生成能力。其最大的特点是可以处理高达4000个词元(token)，是此前Fine-tuning模型的2倍。

在新推出的微调功能中，企业和开发者可以使用自己的数据集对GPT-3.5 Turbo进行监督微调，使其在特定任务上的表现进一步优化。这相当于在通用语言模型的基础上进行进一步“训练”，掌握个性化的知识。

微调后的模型仍然保留GPT-3.5 Turbo的共享请求限制。用户上传的数据仅用于微调自身模型，OpenAI不会基于这些数据继续训练新的模型。这确保了用户数据的隐私性和安全性。

OpenAI表示，今年秋天GPT-4也将开放微调访问。根据早期测试，针对特定狭窄任务微调后的GPT-3.5 Turbo性能甚至可以达到GPT-4的水平。这为用户提供了低成本获取强大NLP模型的途径。

微调的关键优势

相比直接使用GPT-3 API，微调可以给企业和开发者带来多方面的好处:

  1. 性能提升

微调后的模型可以明显改善许多关键任务的性能，比如遵循指示、格式化响应、保持一致的语言风格等。测试显示针对特定任务微调过的GPT-3.5 Turbo可以达到或超过GPT-4的准确率。

  1. 自定义体验

微调允许企业训练出符合自身品牌风格的模型。这在要求语音风格一致的场景下尤其重要，比如客服对话、广告生成等。

  1. 提示工程

在微调后，相同的性能可以通过更短的提示达到。有测试用户表示提示长度缩短了90%。这可以大幅减少计算成本。

  1. 保护数据隐私

微调使用企业自有数据，OpenAI不会复用这些样本。这样企业可以获得个性化的AI能力而无需担心数据隐私。


微调的主要应用场景

OpenAI表示早期使用微调功能的客户已经在多种常见场景中获得了明显的模型性能提升:

  1. 提高可控性

微调可以增强模型遵循特定指示的能力，比如简化输出、始终使用指定语言等。这对需要特定响应格式的应用尤为关键。

  1. 可靠的输出格式

通过微调，可以显著改善模型输出格式的一致性，消除无效响应的随机性。这使得其可以可靠地执行代码补全、API调用等结构化输出任务。

  1. 自定义语调

微调是调整模型语调风格的重要手段，可以训练出符合品牌识别度的语调。这可应用于广告文案、内部沟通等场景。

此外，微调技术还可以和提示工程等其他方法结合，获得 1+1>2 的效果。OpenAI表示后续也将增加对函数调用和16k模型的微调支持。


微调的步骤

使用GPT-3.5 Turbo微调功能主要可以分为以下步骤:

第一步，准备训练数据

用户需要准备好用于微调的高质量训练数据集，一般包含输入文本和期望的输出标签。

{  "messages": [    { "role": "system", "content": "You are an assistant that occasionally misspells words" },    { "role": "user", "content": "Tell me a story." },    { "role": "assistant", "content": "One day a student went to schoool." }  ]}

第二步，上传数据文件

通过OpenAI提供的接口上传训练集文件。

curl -https://api.openai.com/v1/files \  -H "Authorization: Bearer $OPENAI_API_KEY" \  -F "purpose=fine-tune" \  -F "file=@path_to_your_file"

第三步，创建微调任务

配置微调参数，包括模型选择、epoch等，然后创建微调任务。

curl https://api.openai.com/v1/fine_tuning/jobs \-H "Content-Type: application/json" \-H "Authorization: Bearer $OPENAI_API_KEY" \-d '{  "training_file": "TRAINING_FILE_ID",  "model": "gpt-3.5-turbo-0613",}'

第四步，使用微调模型

微调完成后，新的定制模型可以直接用于生产环境中的预测任务，与原始模型共享访问限制。

curl https://api.openai.com/v1/chat/completions \-H "Content-Type: application/json" \-H "Authorization: Bearer $OPENAI_API_KEY" \-d '{  "model": "ft:gpt-3.5-turbo:org_id",  "messages": [    {      "role": "system",      "content": "You are an assistant that occasionally misspells words"    },    {      "role": "user",      "content": "Hello! What is fine-tuning?"    }  ]}'

后续OpenAI还会推出微调的用户界面，让用户更方便地查看微调任务信息、已完成的模型快照等。


安全考量

保障微调过程的安全性对OpenAI来说也是极为重要的。为此他们通过内容审核对训练数据进行过滤，检测不符合要求的不安全内容，确保微调后模型保留通用模型的安全特性。


定价模式

GPT-3.5 Turbo微调的定价包含训练费用和使用费用两部分:

训练费用:每1000词元0.008美元
使用输入费用:每1000词元0.012美元
使用输出费用:每1000词元0.016美元

以一个训练集100万词元、微调3个epoch的任务为例，预计训练成本为2.4美元。

相比直接使用GPT-3 API查询，微调模型的使用价格更高，但可以带来自定义的性能提升。


GPT-3模型更新

此外，OpenAI还推出了babbage-002和davinci-002两种新模型，分别作为之前GPT-3 Babbage和GPT-3 Davinci的替代选项。这两种模型同样可以作为基础模型使用，也支持微调。

为了支持模型的持续进化，新版本微调API端点为/v1/fine_tuning/jobs。老版本的/v1/fine-tunes将在2024年1月下线。

babbage 和 davinci 是两种由 OpenAI 提供的生成式预训练模型。它们在参数数量、训练数据量和能够执行的任务类型方面有所不同:

  • babbage 是相对较小的模型，能够执行一些直接的任务，速度很快，成本较低。它可以做任何  curie 或 ada 能够做的事情。

  • davinci 是最大和最强大的模型，能够理解和生成自然语言或代码。它可以做任何其他模型能够做的任务，通常质量更高。


OpenAI GPT-3.5 Turbo微调功能的开放是语言模型商业化进程中一个重要的里程碑。它为企业和开发者提供了低成本、高性能、可自定义的AI解决方案。

相比通用预训练模型，微调后的GPT-3.5 Turbo可以明显改善许多关键下游任务的性能，并且可以达到或超过更大模型GPT-4的水平。同时，OpenAI也提供了一系列辅助功能和安全保障措施，让整个微调过程更安全、可控。

随着越来越多的组织接入GPT-3微调，我们有望看到基于该技术的创新应用层出不穷。它也将推动个性化、任务定制的AI能力向各个垂直领域普及。未来语言模型训练和应用 的模式亦将更加开放和协作。我们有理由期待一个人工智能创新的春天就在眼前。
