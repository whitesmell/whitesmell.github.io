AnythingLLM：功能强大的本地 AI 应用

产品简介

AnythingLLM 是一款全栈式 AI 应用，它可以将您的任何文档、网页链接、音视频文件甚至只是一段文字，转化为 LLM 可以理解的上下文信息，并在聊天过程中作为参考。您还可以自由选择不同的 LLM 或向量数据库，并进行多用户管理和权限设置。

主要功能

  • • 多用户管理和权限控制： 让团队协作更轻松，每个人都能安全地使用 LLM。

  • • AI Agent 加持： 内置强大的 AI Agent，可以执行网页浏览、代码运行等复杂任务，自动化程度更高。

  • • 可嵌入聊天窗口： 轻松集成到您的网站或应用中，为用户提供 AI 驱动的对话体验。

  • • 广泛的文件格式支持： 支持 PDF、TXT、DOCX 等多种文档类型，满足不同场景需求。

  • • 向量数据库管理： 提供简单易用的界面来管理向量数据库中的文档，方便知识管理。

  • • 灵活的对话模式： 支持聊天和查询两种对话模式，满足不同场景需求。

  • • 信息来源追踪： 聊天过程中会提供引用的文档内容，方便追溯信息来源，增强结果可信度。

  • • 多种部署方式： 支持 100% 云部署，也支持本地部署，满足不同用户的需求。

  • • 自定义 LLM 模型： 可以使用您自己的 LLM 模型，定制化程度更高，满足个性化需求。

  • • 高效处理大型文档： 相较于其他文档聊天机器人解决方案，AnythingLLM 在处理大型文档时效率更高，成本更低，最多可节省 90% 的成本。

  • • 开发者友好： 提供全套开发者 API，方便自定义集成，扩展性更强。

技术架构

AnythingLLM 采用前后端分离的架构，主要由以下四个部分组成：

  • • frontend: 使用 viteJS + React 实现，负责用户界面的展示和交互，提供流畅的用户体验。

  • • server: 使用 NodeJS express 实现，负责处理所有请求，并与向量数据库和 LLM 进行交互，是整个应用的核心。

  • • docker: 提供 Docker 镜像构建脚本，方便用户快速部署，一键启动 AI 应用。

  • • collector: 使用 NodeJS express 实现，负责从用户界面接收和解析文档，为 LLM 提供结构化的数据。

部署方式

为了满足不同用户的需求，AnythingLLM 提供了多种部署方式，包括：

  • • Docker: 使用 Docker 镜像快速部署，简单快捷。

  • • AWS: 部署到 AWS 云平台，享受云服务的便利。

  • • GCP: 部署到 GCP 云平台，享受云服务的便利。

  • • Digital Ocean: 部署到 Digital Ocean 云平台，享受简单易用的云服务。

  • • Render.com: 部署到 Render.com 云平台，享受自动化的部署体验。

  • • Railway: 部署到 Railway 云平台，享受简单易用的云服务。

ChatUI: AnythingLLM 的智能对话界面

AnythingLLM 的 ChatUI 为用户提供了一个直观、易用的界面，用于与 LLM 进行交互。

用户消息

用户消息是您发送给 LLM 的消息，用于提出问题或指令。您可以在用户消息中：

  • • 输入文本，例如“你好，请问今天天气怎么样？”

  • • 粘贴文本，例如从其他文档中复制的内容

  • • 使用语音输入，通过语音转换为文本

用户消息操作

  • • 复制： 将用户消息的内容复制到剪贴板。

  • • 编辑： 修改已发送的用户消息，并重新提交给 LLM。

  • • 朗读： 使用操作系统自带的语音合成引擎或其他语音服务朗读用户消息。

LLM 消息

LLM 消息是 LLM 对用户消息的响应，它可以是文本、代码、表格等多种形式。

LLM 消息操作

  • • 复制： 将 LLM 消息的内容复制到剪贴板。

  • • 编辑： 修改 LLM 消息的输出内容，但这不会重新提交给 LLM。

  • • 重新生成： 使用相同的用户消息和历史记录重新生成 LLM 响应。

  • • 反馈： 对 LLM 响应给出正面或负面反馈，帮助开发者改进模型。

提示输入控件

提示输入控件位于聊天输入框下方，提供了一些便捷功能，例如：

  • • 斜杠命令： 快速插入预定义的文本片段，例如“/reset”可以重置聊天历史记录。

  • • @agent 调用： 触发 AI Agent 执行特定任务，例如“@agent 请帮我搜索一下关于 AI Agent 的最新资讯”。

  • • 字体大小： 调整聊天界面的字体大小。

  • • 麦克风： 启用语音输入功能。

AI Agent：让 LLM 如虎添翼

Agent 概述

AI Agent 是 AnythingLLM 最具特色的功能之一。Agent 就像 LLM 的智能助手，能够访问各种工具，例如网页浏览器、文件系统和 SQL 数据库，从而完成更复杂的任务。您只需使用 @agent 在聊天中触发 Agent，并使用自然语言与其交互，就能轻松指挥它完成各种任务。

Agent 工具介绍

AnythingLLM 的 Agent 目前支持以下工具：

  • • RAG 搜索: 让 Agent 能够根据您上传的文档信息回答问题，就像拥有了一个私人知识库。 

  • • 网页浏览: 让 Agent 能够实时访问互联网获取信息，回答您关于时事、新闻、知识等方面的任何问题。 

  • • 网页抓取: 让 Agent 能够抓取指定网页上的内容并嵌入到工作区中，方便您进行深入分析。 

  • • 保存文件: 让 Agent 能够将重要信息保存到本地文件，方便您查阅和分享。 

  • • 列出文档: 让 Agent 能够列出当前工作区中所有可用的文档，方便您快速找到所需信息。 

  • • 文档摘要: 让 Agent 能够对指定的文档进行摘要，提取关键信息，节省您的阅读时间。 

  • • 图表生成: 让 Agent 能够根据您提供的数据生成图表，直观展示数据分析结果。 

  • • SQL Agent: 让 Agent 能够连接到 SQL 数据库并执行查询，实现数据分析和 insights 获取的自动化。 

Agent 使用案例

  • • 市场分析师: 使用 Agent 抓取竞争对手网站的数据，进行市场分析和竞品调研。

  • • 产品经理: 使用 Agent 收集用户反馈，分析用户需求，为产品迭代提供数据支持。

  • • 软件工程师: 使用 Agent 搜索代码示例，解决技术难题，提高开发效率。

  • • 数据分析师: 使用 Agent 从数据库中提取数据，生成图表，进行数据可视化和分析。

  • • 学生: 使用 Agent 搜索学习资料，完成作业，提高学习效率。
