OpenAI 的 function calling 功能是一项新的功能，它可以让开发者用自然语言来描述函数，并且让模型智能地选择输出一个包含调用这些函数所需参数的 JSON 对象。这样可以方便地将模型的输出与外部的工具或 API 连接起来，实现更复杂的功能。

GPT 模型的一个重要特点是可以通过输入不同的提示（prompts）来实现不同的功能，相当于用自然语言来“编程”模型。例如，可以输入一些指令或示例来让模型完成一个任务，或者输入一些问题来让模型给出答案。

但是，有时候我们可能需要模型与外部的工具或 API 进行交互，例如调用一个天气查询的 API 来回答用户的问题，或者将一个自然语言的查询转换为一个数据库查询。这时候，我们就需要一种方法来让模型知道如何调用这些工具或 API，并且能够返回一个结构化的数据，而不是仅仅返回一段文本。

为了解决这个问题，OpenAI 在 2023 年 6 月推出了一项新的功能：function calling。这项功能允许开发者向 GPT-4 和 GPT-3.5-turbo 这两个最新的模型描述函数，并且让模型智能地选择输出一个包含调用这些函数所需参数的 JSON 对象。这是一种更可靠地将 GPT 的能力与外部工具或 API 连接起来的新方法。

在本文中，我们将介绍 function calling 的概念、优点和场景，并且给出一些使用 function calling 的示例。

什么是 Function Calling

function calling 是 OpenAI 在其 Chat Completions API 中提供的一项新功能，它可以让开发者使用 JSON Schema 来描述函数，并且让模型根据用户的输入来判断是否需要调用这些函数，并且返回一个符合函数签名的 JSON 对象。

function calling 的流程可以分为三个主要步骤：

  1. 调用 OpenAI API 时，提供函数和用户输入。模型会解析用户输入，并且确定调用提供的函数所需的正确参数。

  2. 使用模型返回的 JSON 对象来调用相应的函数。

  3. 将函数返回的结果再次发送给模型，让模型对结果进行总结或格式化，以便人类理解。

Function Calling 的优点和场景


function calling 的优点有以下几点：

  • function calling 可以让开发者更可靠地从模型中获取结构化的数据，而不是仅仅获取一段文本。这样可以方便地将模型的输出与外部的工具或 API 连接起来，实现更复杂的功能。

  • function calling 可以让开发者更灵活地控制模型的行为，通过提供不同的函数来实现不同的功能。例如，可以提供一个 send_email (to: string, body: string) 的函数来让模型发送邮件，或者提供一个 sql_query (query: string) 的函数来让模型执行数据库查询。

  • function calling 可以让开发者更简单地编写提示（prompts），通过提供一些指令或示例来让模型完成一个任务，而不需要编写复杂的逻辑或规则。例如，可以提供一个 extract_people_data (people: [ {name: string, birthday: string, location: string}]) 的函数来让模型从一篇维基百科文章中提取所有人物的信息。


Function Calling 的场景有以下几种：


  • 创建可以回答问题的聊天机器人，通过调用外部的工具或 API 来获取答案。例如，可以调用一个天气查询的 API 来回答用户的天气问题，或者调用一个地图查询的 API 来回答用户的路线问题。

  • 将自然语言转换为 API 调用或数据库查询，通过提供相应的函数来让模型生成 JSON 对象。例如，可以将“谁是我这个月的前十名客户？”转换为一个内部 API 调用 get_customers_by_revenue (start_date: string, end_date: string, limit: int)，或者将“Acme 公司上个月下了多少订单？”转换为一个 SQL 查询 sql_query (query: string)。

  • 从文本中提取结构化数据，通过提供相应的函数来让模型生成 JSON 对象。例如，可以从一篇维基百科文章中提取所有人物的信息，或者从一篇新闻报道中提取所有涉及到的组织和事件。
