Windows 11是微软今年推出的最新操作系统，它不仅拥有全新的界面设计，还集成了许多人工智能（AI）功能，为用户和开发者带来了全新的生产力体验。其中最引人注目的一个功能就是Windows copilot，一个基于ChatGPT技术的智能助理，它可以帮助你完成各种任务，从调整设置到写作文档，都能轻松应对。

Windows copilot是什么？

Windows copilot是一个在Windows 11中内置的应用程序，它可以通过自然语言查询为用户提供个性化的答案，就像ChatGPT和Bing Chat一样。你可以通过任务栏上的一个专用按钮来启动它，然后在屏幕右侧打开一个侧边栏，与它进行交互。

Windows copilot不仅可以回答你的一般问题，还可以根据你的请求执行一些操作，比如调整你的设置，重新排列你的窗口，打开你喜欢的应用程序等等。¹² 它还可以对你拖入侧边栏的文档进行摘要、重写或解释，帮助你提高写作效率和质量。²³

 Windows copilot有什么优势？

Windows copilot的优势在于它可以让每个用户都成为高效用户，无论你是初学者还是专家，都可以通过与它对话来完成你想要做的事情。¹² 它可以让你更方便地掌控和定制你的Windows 11体验，也可以让你更轻松地跨越不同的应用程序和服务，实现无缝连接。

Windows copilot还具有强大的学习能力和扩展性，因为它是基于ChatGPT技术构建的，这是一个开放的人工智能平台，允许开发者为其编写插件和扩展功能。这意味着Windows copilot可以随着时间和用户需求而不断进化和改进，为用户提供更多的可能性和选择。

Windows copilot如何使用？

要使用Windows copilot，你只需要在任务栏上点击copilot按钮，就可以打开侧边栏，并开始与它对话。你可以用自然语言输入你想要问或做的事情，比如“调整我的设置以便我专注”或“打开Spotify并播放我的最爱歌单”。你也可以拖入任何文档到侧边栏，并请求copilot为你进行摘要、重写或解释。

如果你想要关闭copilot或切换到其他应用程序，你只需要点击侧边栏上方的X按钮或按下Esc键即可。

 Windows copilot何时推出？

Windows copilot将于今年6月开始向Windows Insider用户公开测试，并在之后逐步向所有Windows 11用户推送。¹² 如果你想要尽早体验这一智能助理功能，请加入Windows Insider计划，并选择Dev频道获取最新的预览版本。
