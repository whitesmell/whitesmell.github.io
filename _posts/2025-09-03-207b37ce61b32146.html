ChatGPT发布后，人们对大语言模型的能力印象深刻，但一个根本问题仍未解决：这些AI系统到底如何工作？

与传统软件不同，LLMs不是被编程的，而是通过在海量文本上训练"学习"出智能。这个过程创造了复杂的知识和能力，但生成的模型内部机制并不透明。

机制解释性研究试图逆向工程这些AI系统，类似于神经科学研究大脑的方法。本文将基于该领域最新发现，解析LLMs的工作原理。

特别声明：本文的核心内容与深度解析，主要基于AI研究者 Stephen McAleese 在知名科技博客 LessWrong 上发表的深度长文《Understanding LLMs: Insights from Mechanistic Interpretability》。本文在此基础上进行了系统的重构、信息补充与观点提炼，旨在为中文读者呈现一份全面且易于理解的机制解释性研究入门指南。我们对原作者的卓越工作表示诚挚的感谢。

Transformer架构基础

文本到数字的转换

当我们向ChatGPT输入"猫坐在垫子上"时，模型首先将文本转换为数字序列：

  1. 1. 词元化(Tokenization)：文本被分解为词元(tokens)，每个词元可能是完整单词、词的一部分或标点符号
  2. 2. 数字映射：每个词元对应一个数字，如"猫坐在"可能变成[10, 35, 800]
  3. 3. 嵌入向量：数字被转换为高维向量（通常数百到数千维）来表示含义

这种转换解释了LLMs在某些任务上的局限性。例如，数字"1,234"可能被分割成["1", ",", "234"]三个词元，使精确计算变得困难。

嵌入空间中的词汇含义

嵌入层本质上是一个查找表，将每个词元映射到特定的向量。相似含义的词会产生相似方向的向量，在高维空间中夹角较小。

残差流：信息传递的主干道

残差流是Transformer的核心数据流，类似于一个共享工作空间。不同组件从中读取信息并向其写入信息，逐步精炼每个位置的表示。

初始状态代表每个词的孤立含义，随着通过多个层，这些表示被根据上下文不断精炼。

推理的双阶段过程

LLM的推理分为两个阶段：

预填充阶段：并行处理整个输入提示，计算所有位置的注意力关系，生成第一个新词元。这个阶段计算密集但奠定了上下文基础。


解码阶段：逐个生成后续词元。利用KV缓存重用之前的计算，使这个阶段更高效。

注意力机制：上下文理解的核心

注意力机制是Transformer的重要创新，它使模型能够在不同位置间传递信息。

考虑"银行"在两个句子中的不同含义："我在河银行游泳"和"我从银行取钱"。注意力机制让模型根据上下文理解同一词汇的不同含义。

注意力的工作原理

每个注意力头包含两个电路：

QK电路(Query-Key)：确定信息来源。目标词元（查询）计算对所有源词元（键）的注意力权重。

OV电路(Output-Value)：确定传递的信息内容。根据注意力权重，将源词元的值向量加权组合传递给目标位置。

归纳头：算法推理的证据

归纳头(Induction Heads)是一种特殊的注意力头，实现简单但强大的算法："如果A后跟B，当再次看到A时，预测B"。

归纳头的重要性在于它们能处理训练数据中未出现的模式，这证明LLMs能学习算法而非仅仅记忆统计信息。由于归纳头只能在至少两层的Transformer中形成，这表明更深的模型具有质量上不同的算法能力。

复杂推理：间接宾语识别

研究人员分析了"当玛丽和约翰去商店时，约翰给了一杯饮料给___"这类句子，发现了一个三步算法：

  1. 1. 识别所有名字（玛丽、约翰、约翰）
  2. 2. 排除重复名字（约翰）
  3. 3. 输出剩余名字（玛丽）

这个过程由三类专门化注意力头协作完成：

  • • 重复词元头：识别重复出现的名字
  • • S抑制头：从后续处理中排除重复词元
  • • 名字移动头：将非重复名字复制到输出位置

这展示了多头注意力的复杂协调能力。

MLP层：世界知识的存储库

MLP（多层感知器）层占模型参数的约三分之二，被认为是知识存储的主要载体。

键值记忆机制

研究表明，MLP层功能类似巨大的键值存储系统：

第一层权重（键）：作为模式检测器，识别输入中的特定模式

  • • 浅层：检测表面语法模式，如特定词汇结尾
  • • 深层：识别抽象语义概念，如"科技话题"或"时间范围"

第二层权重（值）：存储对应的词汇预测分布，表示检测到模式后最可能出现的词汇

具体例子：给定句子"和你待一段"，有一个键k2被描述时间段且以"段"结尾的输入触发。其对应的值向量v2代表一个概率分布，将大部分概率质量放在词"时间"上。输入句子强烈激活键k2，触发值v2，增加输出分布中"时间"的概率。

分层知识组织

更多MLP参数意味着更大的"记忆"容量，能存储更丰富的语言规则和语义关系。这种知识以分层方式组织：浅层处理语法模式，深层构建复杂的语义理解。

训练过程：从随机到智能的演化

LLMs通过预测下一词进行训练。训练初期权重随机，预测准确率低。随着训练进行，模型逐步掌握语言规律。

学习的三个阶段

1. 统计频率学习：

  • • 单元频率：学习"的"、"是"等常见词的出现概率
  • • 双元频率：学习"北京"+"大学"等常见组合
  • • N-gram序列：掌握三个或更多词元的固定搭配

2. 算法发展：模型开始学习更复杂的规律，如长距离依赖关系。归纳头等复杂电路形成，使模型获得新的推理能力。这个阶段的改进更加渐进。

3. 质变阶段：从简单统计转向可泛化的算法推理。归纳电路的形成可能导致损失曲线的显著下降，因为模型突然获得了强大的上下文学习能力。

奇异学习理论的新洞察

最新研究使用奇异学习理论(Singular Learning Theory, SLT)来识别训练的不同发展阶段。局部学习系数(Local Learning Coefficient, LLC)可以量化损失景观的"简并性"：

  • • 低LLC：高简并性，对应简单模型结构
  • • 高LLC：低简并性，对应复杂模型结构

研究发现，不同学习阶段对应LLC的显著变化：

  1. 1. 学习双元：低LLC期，模型使用简单的高度简并结构
  2. 2. 学习N-gram：随着模型学习使用位置信息和注意力头，LLC开始上升
  3. 3. 形成归纳电路：强大电路的形成标志着LLC的显著增加

这揭示了虽然损失曲线看似平滑连续下降，但训练过程实际上由不同的阶段组成，这些阶段被相变分隔。

顿悟现象(Grokking)

顿悟是神经网络在长期记忆和过拟合后突然快速学会泛化到未见数据的现象。通过研究模数加法的单层Transformer，研究人员识别了三个训练阶段：

  1. 1. 记忆阶段：模型简单记忆训练数据，训练损失快速下降但测试损失保持高位
  2. 2. 电路形成：模型开始形成基于三角恒等式的傅里叶乘法泛化电路
  3. 3. 清理阶段：突然的"顿悟"发生，权重衰减移除记忆组件，测试损失急剧下降

这表明LLMs可以记忆训练数据，然后形成泛化算法。这是合理的，因为泛化解决方案比朴素记忆方法实现更低的损失。

叠加现象与解决方案

特征超载问题

LLMs面临一个根本挑战：需要学习的特征（概念、模式）远超神经元数量。这迫使每个神经元变得"多义"，同时响应多个不相关的概念。

典型特征示例：

  • • 金门大桥特征：被相关文本激活
  • • 脑科学特征：被神经科学、意识或学习概念激活
  • • 纪念碑和旅游景点特征：被蒙娜丽莎或埃及金字塔等景点描述激活

例如，LLM的残差流可能有8192个维度，但现实世界的文本复杂性可能需要数万或数十万个有用特征来理解。

多义神经元如何工作

多义神经元通过利用现实世界训练数据通常稀疏的事实来避免多个特征间的干扰：不太可能有多个无关特征同时激活。例如，如果阿拉伯语特征因阿拉伯文本而激活，中文特征不太可能也在同一文本上激活。

如果数据不稀疏，多义性会导致干扰，神经网络会改为给每个神经元分配一个特征，只学习最重要的特征，忽略其余特征。然而，现实世界文本通常是稀疏的，这意味着叠加和多义性在LLMs中很常见。

稀疏自编码器：破解多义性

稀疏自编码器(Sparse Autoencoders, SAEs)是处理叠加现象的前沿方法，能将复杂的重叠特征分解为更可解释的组件。

叠加假说认为神经网络"想要表示比拥有神经元更多的特征"，处于叠加状态的神经网络是更大稀疏网络的噪声模拟。

SAEs的目标是学习更大的稀疏激活向量，具有三个关键属性：

  • • 单义性：每个特征神经元只响应一个特征
  • • 稀疏性：任何给定输入只激活少量特征，其他设为零
  • • 低重构损失：SAE产生的特征加权和忠实解释原始层激活的功能

SAE由编码器和解码器两层组成。给定输入x，SAE尝试使用学习的特征方向向量的加权和来重构输入：

编码器产生稀疏系数向量，描述处理输入词元时每个特征的活跃程度。解码器使用系数和学习的特征向量的加权和重构原始输入向量。

自动特征解释

SAEs通常学习数千个特征，手动识别每个特征是不现实的。研究人员开发了使用LLM自动标注特征的方法：

  1. 1. 对于每个特征向量，找到最能激活它的顶级文本（如关于金门大桥的句子）
  2. 2. 将这些文本传递给LLM来写出特征的人类可读描述（"金门大桥"）

其他理解特征的方法包括：

  • • 查看特征增加或减少的输出logits（如特征增加"golden"logit）
  • • 将特征固定在高值并观察LLM行为变化（当金门大桥特征激活时，LLM会专注谈论金门大桥）

SAEs的重要发现

Anthropic在《扩展单义性：从Claude 3 Sonnet提取可解释特征》论文中发现：

  • • 找到的特征通常是抽象的、多语言的和多模态的
  • • 特征可以用来引导模型行为
  • • 一些特征与AI安全关切相关，如欺骗、阿谀、偏见和危险内容

电路追踪：揭示推理路径

SAEs识别了模型使用的概念，但未能解释这些概念如何协作完成任务。电路追踪技术通过"电路"来解释任务执行：显示特征间跨层和位置的信息流动图。

转码器技术

电路追踪使用转码器(Transcoders)而非稀疏自编码器：

  • • SAEs：使用特征向量的稀疏加权和重建模型中特定点的向量
  • • 转码器：以MLP层输入为输入，学习重建MLP层输出，可完全替代MLP层

研究人员使用跨层转码器：每个转码器从L层的残差流读取，写入所有后续层。选择跨层而非逐层转码器是因为它们在均方误差(MSE)等指标上表现更好。

与SAEs类似，转码器的目标是最小化重构损失同时最大化特征稀疏性，转码器特征可以基于高度激活它们的文本和激活时增加或减少的输出logits进行标记。

归因图：可视化的推理路径

归因图根据负责模型输出的互联转码器特征子图来解释模型输出。

归因图可以从"局部可解释模型"创建，这是一个替代原始不可解释模型的可解释模型，在给定输入提示p时产生相同输出。在局部可解释模型中，MLP块被跨层转码器替代，原始模型的注意力模式被冻结，并在每个层-位置坐标添加错误项来纠正每个MLP块和转码器间的差异。

然后可以通过修剪通过模型的不重要路径来创建归因图，使模型只用少数转码器特征和它们间的连接来解释。此外，可以将相似的特征节点合并为超节点以减少特征数量。

归因图由节点和边组成。图中有四种类型的节点：

  • • 输入节点：对应输入词元的嵌入
  • • 中间节点：在提示中特定位置激活的转码器特征
  • • 输出节点：对应候选输出词元
  • • 错误节点：对应MLP输出和转码器输出间的差异

归因图中的边量化一个特征对后续层或位置中另一个特征的影响程度。强边表示一个特征的激活是另一个特征的重要因果因子。

验证归因图的正确性

创建归因图时的关键挑战是确保它们忠实反映原始模型的内部工作。为验证这些图，研究人员应用特定扰动，如抑制某些特征的激活，然后检查这些干预是否对模型输出产生预期效果。

例如，在"包含达拉斯的州的首府是"这样的提示中，未修改的局部替换模型正确输出"奥斯汀"。此行为的归因图显示"首府"、"州"和"达拉斯"特征被激活。抑制"达拉斯"特征导致模型输出随机美国州首府如"奥尔巴尼"或"萨克拉门托"，这证实"达拉斯"特征专门导致模型输出德克萨斯州的首府，而非任何州首府。

加法运算案例分析

虽然LLMs只训练预测互联网文本，但它们具备加法能力。电路分析可以提供LLMs如何加数字的洞察。

研究人员分析了LLM如何执行"36 + 59"的加法，发现了三条并行路径：

  1. 1. 左侧路径（低精度路径）：包含低精度查找特征，如"36 + ~59"特征。这些特征贡献"sum = ~92"，增加90左右输出词元的概率。
  2. 2. 中上特征：增加95 mod 100词元的概率（以95结尾的数字，如95, 295, 595），被包括"sum = ~92"特征和"_6 + _9"特征激活。
  3. 3. 右侧路径：涉及增加以5结尾输出词元概率的"_5"特征，被当输入A以6结尾、输入B以9结尾时激活的"_6 + _9"特征激活。

整体图相当复杂，但基本思想是：

  • • 低精度输出特征增加90左右输出词元的概率
  • • 95 mod 100输出特征增加以95结尾词元的概率
  • • 两条路径协作产生正确答案：95

这些输出特征被中间层的特征激活，如被"36"和"59"特征激活的"sum = ~92"特征。这些输入特征在精确词元"36"或以9结尾的词元上触发。

关于LLMs中加法如何工作的研究得出结论：LLMs实现算术能力的机制介于健壮算法和记忆之间——LLMs实现"启发式集合"，即许多记忆规则的组合来执行算术推理。

重新理解"LLMs如何工作"

超越简化解释

常见的LLM解释存在局限性：

  • • "仅仅是统计"：归纳头能处理训练数据中未出现的模式，证明了算法能力超越简单统计
  • • "像计算机程序"：程序执行明确的人工指令，LLMs学习自己的行为并混合代码和数据，能执行文本摘要等传统程序难以实现的任务
  • • "类似人脑"：虽然都擅长学习和模式识别，但LLMs使用Transformer架构，这是有效的深度学习技术但不基于大脑工作原理

更准确的解释：涌现电路

基于机制解释性研究，更准确的高层解释是LLMs通过形成涌现电路来执行任务。

训练过程中，模型学会了几个有助于预测下一词和执行任务的不同能力：

  1. 1. 学习统计：掌握训练数据的双元组和三元组等统计模式
  2. 2. 使用注意力头：在输入不同部分间移动信息，实现上下文信息使用、上下文学习和涉及多个专门注意力头的算法
  3. 3. 使用MLP块：存储有用的世界知识并识别输入模式和特征，然后影响最终预测。特征以叠加方式存储，允许模型学习比神经元数量更多的特征
  4. 4. 分层处理信息：每个连续层通过结合早期层识别的简单特征来构建更复杂和抽象的特征和概念，逐步向最终解决方案迈进

这些不同机制被组合成复杂电路，执行间接宾语识别、加法、事实回忆等高级行为。

技术发展与未来展望

架构演进

虽然本文重点讨论类似GPT-2的架构，但核心原理适用于现代模型。主要优化包括：

  • • 注意力机制：从多头注意力(MHA)到分组查询注意力(GQA)和滑动窗口注意力，大幅减少内存使用并加速长提示推理
  • • 位置编码：从学习的绝对位置嵌入到旋转位置嵌入(RoPE)，更有效处理长上下文
  • • 模型架构：从"密集"架构（所有参数为每个词元激活）到稀疏混合专家(MoE)架构，通过专门"专家"模块大幅增加知识容量
  • • 前馈层：从GELU激活函数到SwiGLU等更先进的门控激活单元
  • • 归一化：从LayerNorm到RMSNorm（均方根归一化），在GPU上计算更简单高效

持续相关性

尽管存在这些差异，2025年Transformer架构及其核心组件（嵌入、自注意力和前馈层）仍被使用，因此任何Transformer可解释性研究仍然相关。

如果Transformer被新架构替代，本文关于注意力头的内容可能不再相关。但是，现代LLMs只是另一种深度学习架构，关于全连接神经网络(MLP块)、特征、叠加、电路和训练动态的洞察似乎更具普遍性，在未来超越Transformer的AI架构中仍将有用，就像它们在卷积神经网络(CNNs)和递归神经网络(RNNs)等Transformer前架构中相关一样。

研究意义与应用前景

机制解释性研究正在将"黑盒"AI系统转变为"白盒"，这不仅具有科学价值，更为AI安全和对齐研究奠定了基础。

理解LLMs的内部机制对于：

  • • AI安全：预测和控制模型行为，识别潜在的偏见、欺骗或危险倾向
  • • 模型改进：基于机制理解优化架构和训练过程
  • • 科学认知：揭示智能和语言理解的计算原理
  • • 实际应用：开发更可靠、可控和可解释的AI系统

具有重要意义。随着这一领域研究的深入，我们对人工智能内部工作原理的理解将继续深化，为构建更安全、更可靠的AI系统提供科学基础。
