OpenAI 发生内乱，萨姆·奥尔特曼离职，首席技术官接任，背后有何隐情？🤖

OpenAI 是一家致力于创造通用人工智能的非营利组织，它的使命是确保人工智能造福全人类，而不是被少数人或机构所控制。

然而，这个崇高的目标似乎并没有让 OpenAI 的董事会和首席执行官萨姆·奥特曼 (Sam Altman) 保持一致。在上周五，OpenAI 宣布，奥特曼将辞去首席执行官职务并离开董事会，由首席技术官米拉·穆拉提 (Mira Murati) 担任临时首席执行官，直到找到永久继任者。😮

这一消息震惊了整个人工智能界，尤其是 OpenAI 的最大合作伙伴和投资者微软。据一位知情人士透露，微软在向全世界分享这一消息的前一分钟才得知 OpenAI 将罢免奥特曼。微软在 2019 年和 2020 年分别向 OpenAI 投资了 10 亿美元和 20 亿美元，以获取 OpenAI 的云服务和人工智能技术的优先使用权。👀

那么，为什么 OpenAI 要解雇奥特曼呢？OpenAI 的董事会在一份声明中表示，他们在经过慎重审查之后，对奥特曼的领导能力失去了信心，认为他在与董事会的沟通中没有始终保持坦诚，妨碍了董事会履行职责的能力。

具体来说，有传言称，奥特曼在卸任 OpenAI 首席执行官一职时，正在为一家专注于硬科技领域的新风投基金募集资金，这可能与他在 OpenAI 的角色和利益发生冲突。此外，他的商业交易一直是硅谷的一个谜团，有人质疑他的投资网络以及是否存在不为人知的财务关系。

奥特曼在 X 上发表文章说，他很喜欢在 OpenAI 工作的日子，这对他个人来说是一次变革，希望对世界也是。他还表示，他对 OpenAI 的未来充满信心，相信米拉·穆拉提是一个出色的临时首席执行官。

米拉·穆拉提是 OpenAI 的首席技术官，也是 OpenAI 领导团队的五年成员。她在 OpenAI 发展成为全球人工智能领导者的过程中发挥了关键作用。她拥有独特的技能，对公司的价值观、运营和业务有深入的了解，并已领导公司的研究、产品和安全职能部门。她还在人工智能治理和政策方面有丰富的经验。

OpenAI 的董事会由 OpenAI 首席科学家 Ilya Sutskever、独立董事 Quora 首席执行官 Adam D’Angelo、技术企业家 Tasha McCauley 以及乔治城安全与新兴技术中心的 Helen Toner 组成。他们表示，他们仍然全力致力于实现 OpenAI 的使命，即确保通用人工智能造福全人类。🙌

作为此次过渡的一部分，OpenAI 的联合创始人之一格雷格·布罗克曼 (Greg Brockman) 也宣布退出该公司。他曾担任董事会主席和总裁，但在奥尔特曼被罢免后，他决定完全离开。他在 X 上分享了一封致员工的信，表达了他对 OpenAI 的感激和自豪。😢

OpenAI 成立于 2015 年，是一家非营利组织，其核心使命是确保通用人工智能造福全人类。2019 年，OpenAI 进行了重组，以确保公司能够筹集资金来实现这一使命，同时保留非营利组织的使命、治理和监督。董事会大部分成员都是独立的，独立董事不持有 OpenAI 股权。尽管公司经历了巨大的发展，但董事会的基本治理责任仍然是推进 OpenAI 的使命并维护其章程的原则。

OpenAI 的领导层变动，无疑给人工智能界带来了巨大的震动。这对 OpenAI 的未来发展，以及与微软等合作伙伴的关系，会产生什么影响呢？我们将继续关注这一事件的后续进展。😉
