本文译自Elad的“Things I Don't Know About AI”，深入探讨了人工智能市场的现状和未来趋势，特别关注了大型语言模型（LLM）的发展，以及云提供商、政府和企业在其中的角色。还对人工智能基础设施公司的发展，以及人工智能云的影响进行了深入分析。最后，作者对人工智能应用的未来趋势进行了预测。

思考问题涉及：

  • 云提供商在人工智能市场中的主导地位会带来哪些影响？

  • 开源模型能否改变人工智能市场格局？

  • 政府会如何支持区域人工智能冠军？

  • 人工智能云会成为未来发展趋势吗？

  • 人工智能在 B2B 和消费者领域的应用潜力如何？

希望这些建议能够帮助您更好地理解和思考人工智能市场的发展趋势。



人工智能领域，我所知甚少

我越是深入研究人工智能市场，就越觉得我对它的了解少之又少。本文列出了一些问题和思考，希望能引发大家的讨论和反馈。

大型语言模型 (LLM) 的问题

LLM 在某种程度上可以分为两类：前沿模型，代表着性能的尖端（例如 GPT-4 和之前的其他模型），以及其他所有模型。2021 年，我曾写过一篇文章，认为由于需要大量资金，前沿模型市场最终会演变成一个寡头垄断市场。与此同时，非前沿模型将更加注重商品化和价格导向，并且开源社区的存在感会更强（注意，这是在 Llama 和 Mistral 发布之前）。

目前，事情似乎正在朝着上述方向发展：

  • 前沿 LLM 很可能成为一个寡头垄断市场。目前，竞争者包括封闭源模型（OpenAI、谷歌、Anthropic、可能还有 Grok/X.ai）以及开源的 Llama (Meta) 和 Mistral。当然，这个名单在未来一两年内可能会发生变化。

  • 前沿模型的训练成本越来越高，而商品模型的性能每年都在提高，价格却在下降（例如，现在训练一个相当于 GPT-3.5 的模型可能比 2 年前便宜 5 倍左右）。

  • 随着模型规模越来越大，资金来源越来越集中在云提供商/大型科技公司身上。例如，微软向 OpenAI 投资了 100 亿美元以上，而 Anthropic 从亚马逊和谷歌获得了 70 亿美元的融资。NVIDIA 也是许多类型基础模型公司的重要投资者。相比之下，风险投资公司对这些公司的投资只是沧海一粟。随着前沿模型训练成本的飙升，新兴的资助方主要集中在大型科技公司（它们通常有强烈的动机为自己的收入资助该领域，例如云提供商或 NVIDIA），或者希望支持本土冠军的国家（例如阿联酋和 Falcon）。这正在影响市场，并促使潜在赢家早早被选出。

值得注意的是，这些云提供商所做的投资规模，与实际的云收入相比是微不足道的。例如，微软的 Azure 每季度能产生 250 亿美元的收入。微软对 OpenAI 的 100 亿美元投资大约相当于 Azure 6 周的收入。这表明，至少目前而言，云业务比任何一个 OpenAI 的模型都重要（如果有人实现了真正的通用人工智能或前沿模型主导地位，情况可能会改变）。事实上，2024 年第二季度，Azure 的人工智能收入增长了 6 个百分点，这意味着其年化增长额将达到 50-60 亿美元（相当于微软对 OpenAI 投资的一半！每年！）。显然，收入并不是净收入，但无论如何，这令人震惊，并表明大型云公司随着时间的推移，有更多理由资助更多的大型模型。

与此同时，Meta 在 Llama 模型方面做了出色的工作，并最近宣布了 200 亿美元的计算预算，部分用于资助大规模模型训练。18 个月前，我曾预测，一个开源的 AI 模型赞助商将会出现，但当时我以为是亚马逊或 NVIDIA，Meta 的可能性较低。(扎克伯格和 Yann LeCunn 在这里很有远见)。

关于 LLM 的问题：

  • 云提供商是否通过提供大量计算/资本资源，在塑造少数玩家成为前沿领域的领导者，并锁定寡头垄断市场？

  • 云提供商什么时候停止资助新的 LLM 基础模型公司，而是继续资助现有公司？云提供商是基础模型最大的资助方，而不是风险资本家。由于反垄断行为，它们在并购方面受到限制，并且云的使用带来了收入，因此这样做是合理的。这可能导致/已经导致了一些市场动态的扭曲。这将如何影响 LLM 的长期经济和市场结构？这是否意味着由于缺乏足够的资金和人才，我们很快就会看到新兴的前沿 LLM 公司消失？或者他们会继续资助大型模型，希望其中一些能转化为云上的收入？

  • 开源模型是否会将人工智能领域的一些经济效益从基础模型转移到云和推理提供商？Meta 是否会继续资助开源模型？如果是，例如 Llama-N 是否能赶上最前沿的水平？一个完全开源的模型，如果在人工智能领域处于最前沿，则有可能将人工智能基础设施的经济份额从 LLM 转移到云和推理提供商，并从其他 LLM 基础模型公司那里吸走收入。这会影响我们如何看待云和基础设施公司在这一市场中的相对重要性。

  • Llama2 使用条款中最精彩的一点是，如果用户少于 7 亿，则可以免费用于商业用途。这显然阻止了一些大型竞争对手使用他们的模型。但也意味着，如果你是一家大型云提供商，你需要向 Meta 支付 Llama 的许可费用，微软已经这么做了。这为 Meta 创造了一种长期控制（和盈利）Llama 的方式，尽管它是开源的。

  • 我们如何看待模型的速度和价格与性能？可以想象，如果速度非常慢但性能非常高，与正常人类速度做事相比，模型可能会非常有价值。最新的巨型 Gemini 模型似乎正朝着这个方向发展，拥有超过 100 万个令牌的上下文窗口，类似于 Magic，它在 2023 年 6 月宣布了 500 万个令牌窗口。大型上下文窗口和理解深度可以真正改变我们对人工智能应用和工程的思考方式。另一方面，Mistral 已经证明了小型、快速、廉价推理模型的价值。下表表明了模型可能最重要的潜在细分市场。

速度价格性能潜在用例
快便宜低实时应用程序，例如聊天机器人、语音助手
快昂贵高需要高性能和低延迟的应用程序，例如自动驾驶汽车、医疗诊断
慢便宜中等不需要实时响应的应用程序，例如文本生成、机器翻译
慢昂贵高需要高性能但延迟不敏感的应用程序，例如科学模拟、药物发现


  • 基础模型的架构如何演变？具有不同架构的代理模型是否会取代部分 LLM 的未来潜力？其他形式的记忆和推理何时会发挥作用？


  • 政府是否会支持（或将其采购转向）区域人工智能冠军？各国政府是否会像在航空航天领域的波音和空客那样，对本地模型进行差异化支出？政府是否希望支持反映其当地价值观、语言等的模型？除了云提供商和全球大型科技公司（例如阿里巴巴、乐天等），其他潜在资金来源就是国家。现在欧洲（例如 Mistral）、日本、印度、阿联酋、中国和其他国家都有优秀的人工智能模型公司。如果是这样，可能会有一些数十亿美元的人工智能基础模型区域公司，仅仅依靠政府收入就能创建。

  • 中国会发生什么？可以预料，中国 LLM 将得到腾讯、阿里巴巴、小米、字节跳动等公司的大力投资，发展本地 LLM 公司。值得注意的是，中国开源模型的趋势。例如，阿里巴巴的 Qwen 在更广泛的 LMSYS 排行榜上名列前茅。

  • X.ai 会发生什么？看起来像一个不确定因素。

  • 谷歌会变得多好？谷歌拥有计算、规模和人才，可以创造出惊人的东西，并且组织有序，行动迅速。谷歌一直是世界上第一家以人工智能为先的公司。看起来像一个不确定因素。

基础设施公司

有几种不同用途的基础设施公司。例如，Braintrust 提供评估、提示词试验场、日志记录和代理，帮助公司从“基于试验场”的人工智能分析转向数据驱动。Scale.ai 和其他公司在数据标注、微调和其他领域发挥着关键作用。其中一些问题比较开放，但没有那么重要（例如，多少 RLHF 会变成 RLAIF）。

人工智能基础设施中最大的不确定性和问题与人工智能云堆栈及其演变有关。对于初创公司和企业，人工智能云服务的需求似乎差别很大。

  • 对于初创公司来说，新的云提供商和工具（例如 Anyscale、Baseten、Modal、Replicate、Together 等）似乎正在走一条有用的道路，导致快速的采用和收入增长。

  • 对于企业来说，他们往往有专门的需求，还有一些开放的问题。例如：

    • 当前的人工智能云公司是否需要为大型企业构建本地/BYOC/VPN 版本的产品？

    • 由于延迟和性能问题，企业似乎会倾向于优化使用他们现有的云市场积分（他们已经为此预算好了），并会犹豫是否要离开他们的 Web 应用程序/数据托管位置（例如 AWS、Azure、GCP）。

    • 企业将关心安全性和合规性（FedRAMP、HIPAA 等）。

    • 短期内人工智能云的初创市场可能与长期的企业需求不同。

  • 人工智能云的采用有多少是由于 GPU/GPU arb 的限制？在主要的云提供商上没有 GPU 的情况下，公司正在争先恐后地为自己的需求找到足够的 GPU，加速了采用拥有自己 GPU 云的新兴创业公司的速度。NVIDIA 可以采取的一种潜在策略是优先将 GPU 分配给这些新提供商，以降低超大规模厂商的议价能力，并分散市场，同时通过创业公司加速该行业。GPU 短缺何时结束，这对新的人工智能云提供商有何影响？

  • 新的人工智能 ASIC（如 Groq）如何影响人工智能云？

  • 还有什么会整合到人工智能云中？他们会交叉销售嵌入式和 RAG 吗？持续更新？微调？其他服务？这对数据标注者或其他有重叠产品的人有何影响？哪些功能会直接整合到模型提供商中，而不是通过云？

  • 人工智能云中的哪些公司会追求哪些商业模式？

  • 值得注意的是，人工智能云世界实际上有两个细分市场：（a）初创公司，（b）中端市场和企业。似乎“仅 GPU”的商业模式默认情况下适用于初创公司（他们对云的需求较少），但对于大型企业的采用，可能会更多地受到主要平台上 GPU 云约束的影响。提供开发者工具、API 端点和/或专用硬件或其他方面的公司是否会转变为另外两个类似的模式 - “Snowflake/Databricks for AI”模式或“Cloudflare for AI”？如果是这样，哪些公司会采用哪些模式？

  • 新的人工智能云会变得多大？像 Heroku、Digital Ocean、Snowflake 还是 AWS 那样大？这个类别的公司的规模和利用率规模是多少？

应用

  • ChatGPT 是许多人工智能创始人的发令枪。在 ChatGPT 之前（以及在那之前不久的 Midjourney 和 Stable Diffusion），大多数科技界人士并没有密切关注我们现在正在经历的 Transformer/Diffusion 模型革命和变革。

  • 这意味着，最接近模型和技术的人 - 也就是人工智能研究人员和基础设施工程师 - 是第一个离开并创办基于此技术的新公司的人。远离核心模型世界的人 - 许多产品工程师、设计师和产品经理 - 直到现在才意识到人工智能的重要性。



  • ChatGPT 大约在 15 个月前发布。如果需要 9-12 个月来决定辞职，几个月来完成辞职，几个月来与联合创始人集思广益提出一个初步的想法，我们应该开始看到一波应用程序构建者现在/很快出现。

  • B2B 应用。在 B2B 应用的新浪潮中，哪些公司和市场将会重要？现任者将在哪些方面获得比初创公司更大的价值？我很快会写一篇关于这个问题的长文。

  • 消费者。可以说，一些最早的人工智能产品是面向消费者或“专业消费者”的 - 也就是说，在个人和商业用例中都可以使用。ChatGPT、Midjourney、Perplexity 和 Pika 就是这样的例子。

  • 也就是说，为什么人工智能生态系统中如此缺乏消费者构建者？仅仅是上述的时间延迟吗？似乎 2007-2012 年社交产品群体已经老化。需要新鲜血液来构建下一波伟大的人工智能消费者产品。

  • 代理。代理可以做很多事情。哪些将是强大的垂直产品领域，哪些是寻找用例的初创公司？


这是我一生中经历过的最激动人心和快速变化的技术时刻之一。看到每个人会构建什么将会很有趣。期待着大家对以上问题的思考。
