2023年，人工智能——特别是生成性人工智能——已经明确地成为主流。似乎每个人都在玩弄大型语言模型（LLM），ChatGPT每周活跃用户超过1亿，实际上已经成为一个家喻户晓的名字。

教师、政治家、脱口秀主持人、公共汽车司机和你的祖父母可能会使用LLM来超越谷歌和古怪的喜剧片段——但这些日常用例只是触及可能的表面。深入挖掘，与该技术密切合作的人们正在使用广泛的人工智能工具来改造产品，重新想象业务，并以以前无法想象的方式提供客户体验......或者，至少，这就是承诺。

那么真实的故事是什么？Retool调查了各种行业的1500多名技术人员——软件工程师、工程师和商业领袖、高管、产品人员、设计师等——以找出答案。继续阅读，了解他们实际上是如何使用AI和构建的。

1、认清事实：对人工智能的真实看法

1.1 人工智能真如其炒作的那样吗？

随着各种嗡嗡声和演示软件的出现，人们很容易沉浸在兴奋之中，但受访者更具洞察力，而不是轻易被迷惑。

事实上，他们普遍认为人工智能有点被高估了，尽管不是那么严重。

1.2 人工智能真的会改变开发人员的学习和工作方式吗？

您可能听说过 StackOverflow 流量下降的传言，以及有关原因的各种理论。

如果人工智能可以取代 StackOverflow，它可以取代……我们的工作吗？

我们听到的关于人工智能取代工作的担忧与我们相信的一样，只要你愿意改变你的工作方式，人工智能 就不会取代工作。

按工作职能切片，运营角色对变化的期望最高（7.8），其次是产品（7.5）以及数据和工程（均在7.4左右）。设计师们不太相信，只有6.8。按资历划分，C级高管预计会出现最大的变化（7.8）。

从农业到医疗保健到媒体再到金融，每个人都预计至少会有一些变化：分数从6（政府工作人员）到8.3（人力资源）不等。

没那么糟糕！

但他们还有一个重大而重要的要求：投资人工智能治理和道德，以确保该技术的未来朝着积极的方向发展。

1.3 给人们他们想要的东西（更多的人工智能？）

虽然对人工智能的看法因角色、行业和实施而略有不同，但大多数受访者认为他们公司的事情进展得很顺利——或者他们渴望更多。

即使在人工智能最大的怀疑论者（认为10/10被高估的受访者）中，也只有14.4%的人表示他们的公司对人工智能投资过度。这不一定是矛盾！相反，它可能表明人们仍然将其视为一项有价值的技术——尽管它可能还不够成熟，或者从受访者的角度来看还没有完全达到质量或实用性门槛。

更进一步，我们要求受访者猜测他们公司追求任何口味的人工智能的潜在动机。他们的印象？节省成本（特别是在500名员工以下的公司）和跟上趋势👀。另一方面，收入影响被视为最不常见的动机，即使只是微不足道的话

至少现在，也许在当前的宏观经济环境中，人工智能似乎可能被视为（被视为）削减成本的一种方式，而不是创造更多业务的一种方式。

1.4 给招聘经理他们想要的东西（具有人工智能技能的候选人）

为了更深入地了解与人工智能相关的感知和变化，我们还要求受访者评估他们雇用候选人有效使用两个特别值得关注的资源——Github Copilot和ChatGPT——编写代码的可能性。

在0到10的范围内，他们的平均得分为6.7，倾向于“更有可能”。

然而，公司规模存在一些差异：在小型公司和刚刚起步的初创公司（1-9名员工）中，可能性最高，为7.1。对于1000-4999的企业来说，它下降了整整一个点，降至6.1。其余的都聚集在平均水平周围。

虽然使用人工智能编写代码的能力对大多数人（63.2%）产生了一定程度的积极影响，但相当一部分受访者（27.1%）仍然相当中立。（受访者很少将副驾驶或ChatGPT技能视为有害。）

所有这些对技术面试意味着什么？回复也同样存在分歧。大多数受访者（60.3%）表示，他们的公司没有改变他们的招聘做法，但该群体中近一半（占总数的28.4%）预计明年会改变。一个不小的少数人（21.2%）表示，他们的招聘流程允许任何和所有人工智能工具。（1,000-4,999名员工的中型企业最有可能——45%——注意到他们的公司增加了技术面试以补偿的难度；所有其他规模的组织都在30多岁到中期。）]

2.实用性和人工智能采用

人工智能——特别是LLM的形式——不再只适用于计算机科学的研究人员和医生，各种公司都注意到了。

那么，企业和构建它们的团队实际上是如何让人工智能发挥作用的呢？

2.1 大多数公司都处于采用人工智能的早期阶段

公司一直在争着比竞争对手更快地将AI实施到他们的流程中，提供相关的“AI产品”，甚至将自己重新定位为“AI公司”，这已经不是什么秘密。

因此，大多数（77.1%）的调查受访者表示，他们的公司已经做出了某种努力来采用人工智能。但大约一半（48.9%）表示，这些努力刚刚起步或临时用例。此外，非平凡的15.7%尚未真正开始，可能也不会很快开始。

让我们谈谈用例

当然，企业在内部和外部都可以采用人工智能。

这是内部和外部用例之间的巨大鸿沟。随着技术、法规和普遍理解的快速发展，内部用例可能会被视为“更安全”或一种试验场。如果公司担心破损、数据问题或缺乏控制，公司可以通过保持内部来提供相对自由裁量权。

2.2 内部人工智能用例涵盖了范围

由于技术员工在这项调查中的代表性比许多公司的名册中要多，工程师们似乎正在得到人工智能的帮助。自动或辅助代码和查询编写（47.5%）和调试帮助（32.4%）相当受欢迎。知识管理——以知识库问答（36.2%）和支持聊天机器人（28.9%）——也相对广泛，文案写作（32.9%）等营销和创意用例似乎得到了一些青睐。

尽管怀疑论者并没有被“这东西太神奇了！”的齐声淹没。受访者普遍认为其公司的内部用例具有一定程度的有用性。（36.8% 的人认为它们“非常有用”，42.9% 的人说“有点用”，16.8% 的人说“有点用”。）只有3.4% 的人说“不太有用”或更糟。

公司在人工智能方面的成熟度与受访者认为人工智能的有用程度之间似乎也存在有意义的相关性。在自称在人工智能采用行业领先的公司工作的受访者中，44.1%的受访者表示该技术“非常有用”。如果公司刚刚完成基础工作？只有27.3%的受访者表示相同。

有趣的是，这些行业领先公司的受访者也最有可能将其描述为没有用，或者有时“完全是浪费时间”。人们对这项技术越熟悉，意见似乎就越强烈——这很公平。

2.3 那些面向客户的用例怎么样？

虽然公司可以构建的可能性几乎是无限的，但大多数受访者面向客户的用途都属于几个关键类别。“产品内功能”——包括工作流程自动化、搜索、可视化、内容审核等——领先（30.6%） ，客户支持聊天机器人（26.5%）和知识库问答（26%）紧随其后。

2.4 准确性和数据安全是痛点

无论您使用它们做什么，今天的人工智能工具都不太可能是完美的。（确实，什么是？）但是了解任何技术的优点和缺点都可以帮助您更好地使用它，而对于受访者来说，输出准确性是最常见的问题。（幻觉——并非完全无关的现象——排在第三位。）

数据安全是另一个首要问题，人们对它的担忧几乎与公司规模呈线性增长：

考虑到这一点，公司仍在研究人工智能如何融入其数据政策。31.7%的受访者表示，他们的公司没有关于人工智能数据使用的明确政策。另外19.8% 的人不确定是否存在政策或具体政策是什么。

另一半受访者确实注意到某种形式的数据政策。最常见的政策要么只允许匿名、非 PII 数据(21.4%)，要么对特定类别的数据施加限制(14.6%)。少数受访者（6.6%）不被允许将任何公司数据与人工智能一起使用；类似的数字(6.2%)可以使用任何数据，只要没有提供商在该数据上训练其模型即可。

不出所料，大公司很可能会对其进行控制。拥有1,000 名以上员工的企业最有可能(90%)制定严格的数据政策。此外，与规模较小的公司相比，规模超过500人的公司更有可能(41-43%)将数据安全视为关键的人工智能问题——只有约 30%的员工人数不足50人的公司也这么认为。

在各个部门和行业中，数据政策的严格程度是不同的。在低端，不到40%的非营利组织(31%)和教育部门(35%)受访者表示，他们的公司实行严格的数据政策。在高端领域，医疗保健(59%)比紧随其后的能源(48%)领先11 个百分点。金融服务通常被认为是严格且高度监管的领域，但处于中间位置，占44%。

2.5（几乎）每个人都在工作中使用人工智能，无论你是否允许他们

虽然工作场所中显然有大量人工智能的使用——54 %在工作中使用人工智能的受访者是在鼓励人工智能的公司中使用——但并非所有事情都是公开的。34.4%的受访者表示他们正在秘密使用人工智能工作，尽管大多数人仍在遵守规则。（57%的受访者表示他们在公司政策范围内使用它。）

这里有一些东西需要解开。当人们都清楚可以公开使用人工智能时，他们却秘密地使用人工智能，这到底是怎么回事？对于那些在黑暗的掩护下使用人工智能的人来说——也就是说，在公司政策之外——有些人可能会违反规则，这是肯定的。但这个数字可能至少部分反映了数据政策的模糊性或尚未制定的政策。这将是一个值得关注的空间，可以看到随着人工智能变得越来越可用、安全和易于理解，我们与人工智能的集体关系将如何变化。

3. 模型领导者

用于定制和改进人工智能应用程序的工具套件正在不断涌现。

哪些基础设施、模型和应用程序正在让奇迹发生——公司正在开发自己的人工智能解决方案来解决哪些问题？

3.1 OpenAI的模型是构建AI应用程序的主要选择

当一家公司想要用人工智能为他们的产品提供动力时，不乏可供选择的法LLM——我们在调查中询问了十几个，受访者可以写下其他的。也就是说，OpenAI 无疑占据了很大的关注度——目前可以说，他们的模型似乎是受访者的默认模型。

ChatGPT 的各种风格（按顺序为4、3.5和3 ）是大多数受访者 (80.1%) 最常用的模型。但如果受访者使用一种模型，他们几乎总是使用另一种模型（88.9%）。当我们询问半常用模型时，事情开始变得更加有趣。这些不同风格的 GPT 仍占近一半（Dall-E 取得了很大的飞跃），而其他类似 Claude 和 LaMDA 的出现则更为重要。 


3.2 超越现成的LLM是例外，而不是规则

由于许多受访者主要使用 OpenAI 模型，因此我们在他们工作的公司中看到类似的模式是合理的。三分之二的受访者(68.7%)表示他们的公司正在使用托管模式。19.6% 的人计划在不久的将来运行开源模型；大约一半使用托管模型的受访者没有计划进行自托管。

剩下约 30%的受访者在 HuggingFace 等云提供商上运行开源模型和完全自托管之间各占一半。

自托管随着公司规模的增加而增加：

深入挖掘后，我们发现近一半(48.1%)的受访者表示他们的公司目前没有对其模型进行任何定制，22.1 % 的受访者表示他们不需要定制。

在谈到开发人员工具时，近40%的受访者表示他们的公司没有使用任何AI基础设施工具；另外约 16%自己建造自己的房子。在受访者排名的工具中，Hugging Face 占据领先地位（尤其是在100 家以下的公司中，有趣的是，超过5000 家的公司，比例从41% 到 54%不等），其次是浪链。

围绕即时工程和测试模型输出的实践似乎也刚刚起步。近四分之一的受访者根本不跟踪即时性能，而另外约 35% 的受访者只进行手动测试。在那些测量和测试新的即时性能的公司中，手动测试在员工人数少于 500 人的公司中最为常见（范围为44-47% ），而对于中型企业来说，手动测试显着下降至32% 。内部工具扭转了这种模式，中型企业占23% ， 500 岁以下的公司占9-15%。

3.3 Copilot 正在吞噬世界（与 ChatGPT 一起）

尽管许多公司仍在站稳脚跟，但人工智能对于工程师的作用似乎正在具体化。GitHub Copilot 等工具在受访者目前使用（和喜欢）的功能中处于领先地位。值得注意的是，有时被称为“人工智能结对程序员”的 Copilot不仅被工程(42%)等技术团队使用，甚至设计团队(13%)和运营(22%)也表示他们使用它。

在我们询问的19 项功能中，只有两项被超过10%的受访者使用：Copilot 和 Grammarly。（上面，我们仅显示了至少1%的受访者使用的功能。）大约五分之一的受访者没有使用任何功能。

当然，某个功能的受欢迎程度可能在某种程度上取决于该产品的整体受欢迎程度、该功能的成熟度和可用性等。由于 GitHub 拥有超过1亿用户，而 Grammarly 的出现时间比名单上的大多数其他公司都要长几年，更不用说对于许多受访者来说，编写代码和文字的内在必要性，这两者很可能具有一些固有的优势。

可是等等！还有更多。作为 GitHub Copilot 已实现一定程度的产品市场契合度的进一步证据，68%的受访者将其列为最重要的三个AI助手之一，仅次于 ChatGPT，后者几乎在所有受访者(96.9%) 中排名前三。（Google Bard 在这场三人赛中排名第三，得分为47.6%。）

目前，就特定工具而言， Copilot 很可能是人工智能“杀手级应用”的一个例子：高使用率、高影响力（参见：StackOverflow）、高满意度。

3.4 谈到矢量数据库，现在还处于早期阶段。

由于公司大多使用开箱即用的托管模型，矢量数据库更像是一个未开发的领域，只有不到20%的受访者正在使用矢量数据库。

但使用它们可能就意味着喜欢它们：所有排名前半部分的流行度都被评为相对中立到积极的。

考虑到所有这些，目前采用率较低可能有多种原因——三分之二以上的公司处于早期阶段，其中最主要的是托管模型。尽管如此，还是有层次的：有些人可能缺乏投资资源，团队可能没有必要的专业知识，而其他人可能不知道随着人工智能实施的成熟，向量数据库可以提供的价值。恰当的例子：一些书面答案思考它们是否是一项好的投资。（无耻插件：如果您好奇但还没有准备好提交，Retool 提供对开箱即用的矢量数据库的免费访问。）

在目前使用矢量数据库的相对较小的受访者中，没有明显的赢家——尽管 Pinecone 正式以20.1% 的比例领先，其次是 MongoDB（19.4%）和 pg_vector（17.8%）。还有一些按公司规模聚集的模式（但请记住，它们可能会受到此处样本量较小的影响）。

进一步剖析数据，最引人注目的数字出现在员工人数为500 至 999人的公司中。使用矢量数据库的括号中的63%表示它是 pg_vector（是大多数其他公司规模的两倍多）；他们还报告称，与其他规模的公司相比，松果的使用率(19%)要低得多，其他规模的公司的松果使用率通常在30%到40% 左右。

总而言之，随着该领域的成熟，它可能是任何人的游戏。


4.那么2023年人工智能的状况如何？

虽然人工智能的许多要素对于日常用户来说仍然遥不可及，但LLM今年却呈爆炸式增长。目前，公司主要是GitHub Copilot 等人工智能应用程序的消费者，如果他们正在构建自己的东西，很可能是使用GPT- 4（或3.5 …或3 …）的内部用例。

随着形势的发展，公司是否会开始微调他们的模型，用向量数据库增强模型，并迭代他们的LLM提示？他们会为人工智能的使用制定深思熟虑的政策和护栏，并鼓励秘密使用LLM的员工公开使用它们吗？我们拭目以待。

很明显，无论他们是看涨、看跌还是只是随波逐流，各个行业和角色的技术人员都在认真思考人工智能技术的可能性和影响，以及它们将如何塑造未来的许多方面。我们认为，这一充满活力的篇章仅仅是一个开始。
