Dropbox Dash 不仅仅是一个搜索工具，更是一个 AI 驱动的全新工作平台。它通过整合碎片化的信息、提供智能化的洞察和简化协作流程，彻底改变团队的工作方式，将效率、协作和安全提升到一个新的水平。

信息过载：现代办公的隐形杀手

你是否曾经花费数小时寻找一个文件，却发现它隐藏在电子邮件的某个角落？你是否曾经因为信息分散而错过重要的会议或截止日期？

在当今快节奏的商业环境中，我们每天都被海量的信息淹没，各种应用和平台层出不穷。电子邮件、云存储、聊天工具、项目管理软件…… 每个工具都存储着重要的信息，但它们彼此孤立，如同散落的珍珠，难以串联成完整的项链。

为了解决这个问题，Dropbox 于 2023 年 10 月推出了 Dash，一款面向个人用户的 AI 驱动的全新工作平台。随后，在 2024 年 10 月，Dropbox 又推出了 Dash 企业版，为团队协作带来了更强大的功能。

Dropbox Dash 启动页

信息过载已经成为现代办公的隐形杀手，它悄无声息地侵蚀着我们的时间、效率和安全：

  • • 时间黑洞： 员工花费大量时间在不同应用间切换、搜索信息，宝贵的时间被无情吞噬。

  • • 协作低效： 信息分散导致沟通不畅、信息不对称，团队协作效率低下，项目推进缓慢。

  • • 安全隐患： 敏感信息散落在各个平台，难以统一管理和保护，存在数据泄露的风险。

我们需要一个能够整合信息、提升效率、增强协作、保障安全的全新工作平台。

Dropbox Dash：用 AI 重塑办公体验

Dropbox Dash 应运而生，它不仅仅是一个搜索工具，更是一个 AI 驱动的全新工作平台。 Dash 通过以下核心功能，为团队带来前所未有的办公体验：

1 全域搜索 (Universal Search)：化繁为简，一键直达

你是否厌倦了在无数个应用和平台中苦苦搜索信息？ Dash 的全域搜索 (Universal Search) 功能让你告别这种烦恼。

Dash 全域搜索界面

跨应用搜索： Dash 可以连接 Dropbox、Google Workspace、Microsoft 365、Slack、Jira、Salesforce 等常用办公应用，实现跨平台、跨应用的统一搜索。你只需在 Dash 中输入关键词，即可找到所有相关信息，无需在不同应用间来回切换。

自然语言搜索： Dash 的 AI 引擎能够理解你的搜索意图，即使你使用口语化的表达方式，例如“上周市场部的会议纪要”，Dash 也能精准地找到你想要的信息。

实时内容建议： Dash 会根据你的输入实时提供内容建议，帮助你更快地找到目标信息，就像一个智能助手，时刻为你提供帮助。

全域搜索的意义不仅仅是节省时间，更重要的是打破信息孤岛，让所有信息都触手可及，为高效工作奠定基础。

2 AI 驱动的 Answers：洞察先机，化解信息焦虑

面对海量的信息，你是否感到无所适从？ Dash 的 Answers 功能利用 AI 技术，为你提炼关键信息，化解信息焦虑。

Dash Answers 功能示例

自然语言提问： 你可以用自然语言向 Dash 提问，例如“这份报告的关键结论是什么？”、“这个项目的截止日期是什么时候？”，Dash 会像一位专业的分析师，为你提供精准的答案。

AI 自动总结： Dash 可以自动总结文件内容，提取关键信息，为你节省宝贵的阅读时间。你只需浏览 Dash 提供的摘要，即可快速了解文件内容，无需逐字逐句阅读。

相关内容推荐： Dash 会根据你的问题和搜索历史，推荐相关的内容，帮助你拓展知识边界，发现新的 insights。

Answers 功能的价值在于，它不仅仅提供信息，更提供洞察。它帮助你快速抓住关键信息，做出更明智的决策。

3 Stacks：智能整理，协作更流畅

你是否为杂乱无章的文件和链接而感到头疼？ Dash 的 Stacks 功能帮助你智能地组织信息，让协作更流畅。

Dash Stacks 功能示例

智能归类： Stacks 可以将相关文件、链接、应用程序等内容一键归类，形成一个 Stack。例如，你可以将一个项目的相关资料都归类到一个 Stack 中，方便查找和共享。

灵活共享： 你可以轻松地将 Stack 分享给团队成员或外部合作伙伴，并设置不同的访问权限，确保数据安全。

Stacks 的价值在于，它让信息组织变得更加智能和便捷，团队成员可以轻松地访问和共享项目资料，提升协作效率。

4 Start Page (起始页)：个性化工作台，开启高效每一天

你是否希望有一个能够一站式管理所有工作内容的平台？ Dash 的 Start Page (起始页) 就是你梦想中的个性化工作台。

Dash Start Page 示例

一站式管理： Start Page (起始页) 整合了你常用的应用程序、最近访问的文件、即将召开的会议等信息，让你在一个界面即可掌控所有工作内容。

个性化推荐： Dash 会根据你的工作习惯和项目进度，为你推荐相关的内容和工具，帮助你更高效地完成工作。

团队动态： Start Page (起始页) 可以显示团队成员的最新活动和项目的进展情况，让你随时了解团队动态，保持信息同步。

Start Page (起始页) 的价值在于，它为你提供了一个清晰、简洁、高效的工作界面，让你可以专注于最重要的工作，提升工作效率。

5 Admin Console (管理员控制台)：集中管理，掌控全局

作为团队管理员，你是否希望能够集中管理 Dash 的所有设置和权限？ Admin Console (管理员控制台) 正是为了满足你的需求而设计的。

Dash Admin Console 界面

用户管理： 你可以通过 Admin Console (管理员控制台) 添加、删除和管理用户，分配角色和权限，确保每个用户都拥有合适的访问权限。

应用管理： 你可以集中管理 Dash 连接的应用程序，配置应用程序的权限和设置，确保团队成员能够安全地访问和使用应用程序。

安全策略： 你可以通过 Admin Console (管理员控制台) 配置 Dash 的安全策略，例如密码策略、双因素认证等，提升团队整体的安全水平。

Admin Console (管理员控制台) 的价值在于，它让团队管理员能够集中管理 Dash 的所有设置和权限，简化管理流程，提升团队的安全性和效率。

6 Surfaces ：随时随地，访问 Dash

你是否希望能够随时随地访问 Dash，无论是在电脑前、会议室还是旅途中？ Dash 的 Surfaces 功能让你梦想成真。

Dash 桌面应用示例

桌面应用： 你可以将 Dash 安装到你的 Mac 或 Windows 电脑上，通过快捷键快速访问 Dash，享受高效的桌面办公体验。

网页浏览器： 你可以通过任何网页浏览器访问 Dash，例如 Chrome、Edge 等，无论你身在何处，都能随时访问你的工作内容。

移动设备： Dash 还提供了移动应用程序，你可以在手机或平板电脑上访问 Dash，随时随地查看文件、Stacks 和团队动态，保持信息同步。

Surfaces 功能的价值在于，它让 Dash 变得无处不在，你可以随时随地访问你的工作内容，提升工作的灵活性和效率。

7 Connectors (连接器)：连接一切，扩展无限可能

你是否希望 Dash 能够连接更多的应用程序，扩展更多的功能？ Connectors (连接器) 功能让你可以将 Dash 与你常用的应用程序连接起来，例如 Asana、Notion、Zoom 等等。

Dash Connectors 功能示例

丰富的应用程序集成： Dash 支持丰富的应用程序集成，你可以将 Dash 与你常用的应用程序连接起来，例如项目管理工具、客户关系管理工具、沟通工具等等。

统一搜索： 连接应用程序后，你可以在 Dash 中统一搜索所有应用程序的内容，无需在不同应用程序之间来回切换。

自动化工作流程： Connectors (连接器) 功能还可以帮助你自动化工作流程，例如，你可以设置当一个新的任务在 Asana 中创建时，自动在 Dash 中创建一个 Stack，并将相关文件添加到 Stack 中。

Connectors (连接器) 功能的价值在于，它让 Dash 变得更加开放和灵活，你可以根据你的需求连接不同的应用程序，扩展 Dash 的功能，打造属于你自己的工作平台。

安全与控制：守护企业数据资产

数据安全是企业发展的基石。 Dropbox Dash 深知这一点，并提供了强大的安全和控制功能，守护企业数据资产。

Dash 安全控制功能示例

精细的权限控制： 你可以为每个文件、文件夹和 Stack 设置不同的访问权限，例如只读、可编辑、可下载等，确保敏感信息只对授权用户开放。

集中式管理平台： Dash 提供了集中式的管理平台，方便管理员管理用户、监控使用情况、配置安全策略，提升管理效率，降低安全风险。
