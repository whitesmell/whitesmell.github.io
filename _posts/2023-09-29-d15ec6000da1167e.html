树莓派是一款广受欢迎的微型计算机，自从2012年推出以来，就在创客和嵌入式工业市场中占据了重要的地位。四年前，树莓派4发布了，为用户带来了更强大的性能和更多的功能。现在，树莓派5终于来了，它不仅比前代更快，而且还是第一款使用自主研发的芯片的树莓派。

尽管之前有人怀疑树莓派5会在今年发布，但这款最新的微型计算机还是带着一些显著的升级，以60美元的起售价出现在了市场上。它不仅能够提供比前代更好的性能，而且还是第一款使用自主研发的芯片的树莓派。

树莓派5的核心是一颗64位四核Arm Cortex-A76处理器，运行频率为2.4GHz，相比于四年前的树莓派4，它能够提供两到三倍的性能提升。这款设备还配备了一颗800MHz的VideoCore VII图形芯片，树莓派基金会称它能够提供“显著的”图形性能提升。

Raspberry Pi 5 还包括了以下新功能：

双 4Kp60 HDMI 显示输出：可以同时连接两台显示器，支持 4K 60Hz 显示。这使得 Raspberry Pi 5 可以用于构建多屏幕显示系统，例如在家庭影院或会议室中。

4Kp60 HEVC 解码器：可以流畅播放 4K 60Hz 的 HEVC 视频。这使得 Raspberry Pi 5 可以用于流媒体播放、视频编辑等应用。

双频 802.11ac Wi-Fi®：支持 2.4GHz 和 5GHz 双频 Wi-Fi，速度更快、覆盖范围更广。这使得 Raspberry Pi 5 可以用于在更广泛的环境中连接到互联网。

蓝牙 5.0 / 蓝牙低功耗 (BLE)：支持最新的蓝牙标准，可以连接更多设备。这使得 Raspberry Pi 5 可以用于构建智能家居或物联网应用。

支持 SDR104 模式的高速 microSD 卡接口：可以利用 microSD 卡的高速读写性能，进行数据传输或运行高性能应用。这使得 Raspberry Pi 5 可以用于数据中心或高性能计算应用。

2 个 USB 3.0 端口：可以连接高速外设，如固态硬盘或高分辨率显示器。这使得 Raspberry Pi 5 可以用于数据存储或图形处理应用。

PCIe 2.0 x1 接口：可以连接 PCIe 扩展卡，扩展 Raspberry Pi 的功能。这使得 Raspberry Pi 5 可以用于更复杂的应用，如深度学习或机器人控制。

Raspberry Pi 5 的配件包括：

更新外壳：采用了新的设计，更加美观。外壳采用了新的材料和工艺，可以更好地散热。

主动冷却器：可以帮助 Raspberry Pi 在高负载下保持凉爽。主动冷却器采用了风扇或液冷系统，可以更有效地散热。

27W USB-C 电源：可以为 Raspberry Pi 提供充足的电力。USB-C 电源可以为 Raspberry Pi 提供更高的功率输出，满足高性能应用的需求。

摄像头和显示屏电缆：可以快速连接摄像头和显示屏。摄像头和显示屏电缆采用了新的设计，可以更方便地连接 Raspberry Pi。

PoE+ HAT：可以通过以太网供电。PoE+ HAT 可以让 Raspberry Pi 通过以太网供电，无需额外的电源连接。

M.2 HAT：可以扩展 Raspberry Pi 的存储容量。M.2 HAT 可以连接 M.2 SSD，为 Raspberry Pi 提供更大的存储空间。

Raspberry Pi 初学者指南，第五版：提供了 Raspberry Pi 的使用说明。Raspberry Pi 初学者指南进行了更新，涵盖了 Raspberry Pi 5 的新功能。

RTC 纽扣电池：用于保存 Raspberry Pi 的时间。RTC 纽扣电池可以确保 Raspberry Pi 在断电后仍然可以保持时间。

树莓派5有一个由树莓派基金会自主研发的组件：南桥，也就是芯片组的一部分，它能够帮助设备与外部设备进行通信。有了RP1南桥，树莓派基金会表示，这款微型计算机“在外设性能和功能方面实现了质的飞跃”，能够实现更快的传输速度，连接外部UAS驱动器和其他外设。

它还开放了两个四通道1.5Gbps的MIPI收发器，让你可以连接两个摄像头或显示器。还有一个新的单通道PCI Express 2.0接口，首次支持“高带宽外设”。不过，树莓派基金会指出，你仍然需要一个单独的适配器，比如一个M.2 HAT（硬件附加在顶部），才能利用它。

在端口方面，你可以期待双4Kp60 HDMI显示输出，支持HDR，一个microSD插槽，两个USB 3.0端口，两个USB 2.0端口，千兆以太网，和一个5V DC电源连接，通过USB-C。一些其他的亮点包括支持蓝牙5.0和低功耗蓝牙（LE），以及使用SDR104高速模式时，SD卡性能“翻倍”。这些升级使得树莓派5更加多功能，无论你是用它作为一个超低预算的桌面电脑，一个媒体服务器，还是一个自制的安全系统。

树莓派5在发布时会有几种不同的内存选项，4GB的版本售价为60美元，8GB的版本售价为80美元。这使得它比树莓派4稍微贵一点，树莓派4的4GB内存版本售价为55美元，8GB内存版本售价为75美元。树莓派5将在10月底之前上市。

树莓派5是一款值得期待的微型计算机，它不仅拥有自主研发的芯片，还提供了强大的性能和丰富的功能。如果你是一个树莓派的爱好者，或者想要尝试一些有趣的创意项目，那么你一定不要错过这款新品。我相信，它会给你带来更多的惊喜和乐趣。
