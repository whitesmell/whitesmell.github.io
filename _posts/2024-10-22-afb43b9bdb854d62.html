以 OpenAI o1 为代表的新一代 AI 模型推理能力显著增强，推动 AI 应用热点从 Copilot、RAG 升级到 Agent。微软发布全新 Agent 功能，包括 Copilot Studio 自主 Agent 创建功能和 Dynamics 365 十大自主 Agent，标志着微软 AI 从 Copilot 向 Agent 升级，旨在推动 AI-first 业务流程变革，赋能更多企业构建和使用自主 Agent，提升运营效率。

OpenAI o1 强势赋能：Agent 引领 AI 应用新浪潮

随着以 OpenAI o1 为代表的新一代 AI 模型推理能力显著增强，AI 应用的热点正经历着从 Copilot、RAG（检索增强生成） 到 Agent 的快速迭代。Agent，作为 AI 驱动世界的全新应用，将彻底改变人与软件的交互方式，为企业带来前所未有的效率提升和价值创造。

Agent 的兴起并非偶然，而是 AI 技术发展到一定阶段的必然结果。 OpenAI o1 等模型的强大推理能力，赋予了 Agent 更强的自主性和智能性，使其能够胜任更复杂的任务，并与用户进行更自然、更流畅的交互。

从最初由 GPT-4 赋能的 Copilot，到如今由更先进的 O1 驱动的 Agent，微软始终走在 AI 应用的前沿。 微软在 AI 领域的探索从未止步。财富 500 强企业中，已有 60% 选择使用 Microsoft 365 Copilot，例如 Lumen Technologies 预计每年可节省 5000 万美元，Honeywell 的生产力提升相当于增加了 187 名全职员工，Finastra 则将创意制作时间从 7 个月缩短至 7 周。这些成功案例充分证明了 Copilot 的强大实力，也为 Agent 的发展奠定了坚实的基础。

在 AI 浪潮席卷全球的今天，微软再次引领潮流，发布了全新的 Agent 功能，将 AI-first 业务流程 带给每一个组织。此次发布的两大亮点分别是：Copilot Studio 自主 Agent 创建功能，将于下个月公开预览；Dynamics 365 十个全新自主 Agent，旨在为销售、服务、财务和供应链团队提升效率。

那么，Agent 究竟是什么？它又将如何引爆企业效率革命？

简单来说，Agent 就像您的 AI 员工，能够自主理解您的需求并执行相应的操作。它们可以自动处理各种任务，例如：

  • • 收集和分析数据

  • • 生成报告和预测

  • • 自动化业务流程

  • • 与客户和供应商进行沟通

  • • 提供个性化建议

想象一下，您的企业拥有一个 24/7 全天候工作的 AI 团队，不知疲倦地处理各种繁琐的任务，将您从日常事务中解放出来，专注于更重要的战略决策。

微软将 Agent 视为 AI 驱动世界的全新应用，如同智能助手般，它们将代表个人、团队或职能部门执行和协调业务流程，从简单的提示和响应到完全自主，无所不能。可以预见，未来每个组织都将拥有各种各样的 Agent，它们将协同工作，加速潜在客户生成、处理销售订单、自动化供应链等，推动企业迈向更高效、更智能的未来。

Agent 应用场景：释放 AI 潜能，重塑业务流程

微软自身以及其客户已经开始在各个领域探索 Agent 的应用，并取得了显著成效。以下是一些典型的 Agent 应用场景：

  • • 销售和市场营销: 销售资格 Agent 可以帮助销售人员筛选潜在客户，确定机会优先级，并提供个性化邮件和回复指导，从而提高销售效率和转化率。微软的某个销售团队使用 Copilot 后，每个销售人员的收入提高了 9.4%，交易量增加了 20%。 市场营销团队可以使用 Agent 自动生成营销文案、管理社交媒体账户、以及分析市场数据，从而提升品牌知名度和市场份额。例如，Azure.com 的转化率提高了 21.5%，这要归功于一个旨在帮助买家的自定义 Agent。

  • • 客户服务: 客户意图 Agent 可以分析客户数据，识别客户意图，并为客户服务代表提供个性化的服务建议，从而提升客户满意度和忠诚度。客户知识管理 Agent 可以与客户服务代表携手合作，学习如何解决客户问题，并自主添加基于知识的文章，以便在整个服务团队中推广最佳实践。例如，微软的某个团队使用 Copilot 后，解决客户案例的速度提高了近 12%。

  • • 财务和运营: 财务预测 Agent 可以利用历史数据和机器学习算法，自动生成准确的财务预测报告，帮助企业做出更明智的财务决策。例如，微软的财务团队使用 Copilot 后，将月度预测流程缩短了 50%。 欺诈检测 Agent 可以实时监控交易数据，识别潜在的欺诈行为，并及时发出警报，帮助企业降低财务风险。供应链风险管理 Agent 可以识别和评估供应链中的潜在风险，例如供应商延迟、自然灾害等，并帮助企业制定风险 mitigation 计划。

  • • 人力资源: 人力资源招聘 Agent 可以自动筛选简历、安排面试，并为候选人提供个性化的招聘体验，从而提高招聘效率和质量。员工培训 Agent 可以根据员工的技能和经验，推荐合适的培训课程，并跟踪员工的学习进度，从而提升员工技能和工作效率。例如，在人力资源方面，员工自助服务 Agent 正在帮助以提高 42% 的准确性来回答问题。

  • • 法务: 法务团队可以利用 Agent 提高处理监管工作的效率，例如自动审查合同、识别法律风险等，从而降低成本和提高效率。 例如，法务团队利用 Agent 提高了处理监管工作的效率，预计每年可节省高达 40% 的成本。

  • • 其他应用场景: Agent 还可以应用于其他各种场景，例如 IT 运营、项目管理、产品开发等等，帮助企业实现更高效、更智能的运营。

Copilot Studio：打造您的专属 AI 员工

为了让更多企业能够轻松构建和使用自主 Agent，微软推出了 Copilot Studio。Copilot Studio 就像一个 Agent 的孵化器，它提供了简单易用的低代码设计界面和预构建连接器，即使没有专业的 AI 知识，也能轻松创建和管理 Agent。

Copilot Studio 界面

Agent 可以利用 Microsoft 365 Graph、记录系统、Dataverse 和 Fabric 中的工作数据上下文，支持 IT 帮助台、员工入职等各种场景，并充当销售和服务的私人礼宾服务。

今年早些时候，微软宣布了 Copilot Studio 的一系列强大新功能，包括创建自主 Agent 的能力。下个月，这些功能将从私人预览转向公开预览，这意味着更多企业将有机会利用 AI 重塑关键业务流程，释放 Agent 的无限潜能。

Clifford Chance、McKinsey & Company、Pets at Home 和 Thomson Reuters 等组织已在使用 Copilot Studio 创建自主 Agent，并取得了令人瞩目的成果。例如，Pets at Home 创建了一个 Agent，帮助其利润保护团队更有效地汇编案例，以供熟练的人工审核，这有可能每年节省 7 位数的成本。McKinsey & Company 正在创建一个 Agent，以加快客户入职流程。试点结果表明，交付周期可以缩短 90%，管理工作可以减少 30%。Thomson Reuters 构建了一个专业级 Agent，以加快法律尽职调查工作流程，初步测试表明，某些任务可以节省一半的时间。

Copilot Studio 核心功能详解

1. 自主触发器

Agent 可以自动响应来自不同工具、系统和数据库的信号，并根据预设的事件或触发器启动任务，无需人工干预。例如，当收到新的客户咨询邮件时，Agent 可以自动回复邮件，并根据邮件内容，将客户信息录入 CRM 系统。

Copilot Studio 自主触发器

2. 动态 Agent 计划

Agent 能够根据不同的业务流程动态创建计划并执行任务。用户可以查看每个 Agent 路径的底层逻辑，包括关键细节、步骤和所涉及的系统，以便了解 Agent 的决策过程和上下文。例如，当处理客户订单时，Agent 可以根据订单金额、库存情况、配送地址等信息，动态选择最佳的配送方案。

Copilot Studio 动态 Agent 计划

3. 活动概览

Copilot Studio 提供了一个“活动”选项卡，用户可以查看 Agent 运行的完整日志，包括进度跟踪、阻塞识别、趋势分析和早期决策回顾，以提高透明度和问责制。例如，用户可以查看 Agent 处理过的所有客户订单，以及每个订单的处理时间、状态、涉及的步骤等信息。

Copilot Studio 活动概览

4. 新模型支持

Copilot Studio Agent 使用最新的模型，包括 OpenAI o1 系列，该系列针对高级推理任务进行了优化，增强了 Agent 解决复杂问题的能力。

Dynamics 365：十大自主 Agent 赋能业务团队

Dynamics 365 中新增的十个自主 Agent 涵盖了销售、服务、财务和供应链等多个领域，为不同团队提供了强大的支持。这些 Agent 旨在帮助团队提高效率、优化运营并提升客户体验。

Dynamics 365 十大自主 Agent 详解

1. 销售资格 Agent

该 Agent 可以帮助销售人员专注于高优先级的销售机会，同时自动研究潜在客户、确定机会优先级，并通过个性化电子邮件和回复引导客户沟通。

例如，该 Agent 可以通过分析来自 LinkedIn、Twitter 等平台的公开数据，以及企业内部 CRM 系统中的客户信息，评估潜在客户的购买意向和资质；根据潜在客户的规模、行业、预算等因素，以及销售人员的经验和能力，预测每个销售机会的成功概率，并进行排序；根据潜在客户的兴趣和需求，自动生成个性化的邮件内容和话术，帮助销售人员更高效地与客户沟通。

Dynamics 365 销售中心界面

2. 供应商沟通 Agent

该 Agent 可以帮助客户优化供应链并最大程度地减少代价高昂的供应中断。它能够自主跟踪供应商绩效、检测延迟并做出相应的响应，从而使采购团队从耗时的手动监控和救火中解放出来。

3. 客户意图 Agent

在客户服务领域，第一印象至关重要。客户意图 Agent 可以帮助客户服务团队应对高呼叫量、人才短缺和不断提高的客户期望。它可以通过分析客户数据，识别客户的意图，并为客户服务代表提供个性化的服务建议，帮助客户服务代表更快地解决客户问题，并提供更优质的服务体验。

4. 客户知识管理 Agent

客户知识管理 Agent 可以与客户服务代表携手合作，学习如何解决客户问题，并自主添加基于知识的文章，以便在整个服务团队中扩展最佳实践。

5. 财务预测 Agent

财务预测 Agent 可以利用历史数据和机器学习算法，自动生成准确的财务预测报告，帮助企业做出更明智的财务决策。

6. 欺诈检测 Agent

欺诈检测 Agent 可以实时监控交易数据，识别潜在的欺诈行为，并及时发出警报，帮助企业降低财务风险。

7. 供应链风险管理 Agent

供应链风险管理 Agent 可以识别和评估供应链中的潜在风险，例如供应商延迟、自然灾害等，并帮助企业制定风险 mitigation 计划。

8. 项目管理 Agent

项目管理 Agent 可以帮助项目经理跟踪项目进度、分配资源、管理预算，并及时识别和解决项目风险。

9. 人力资源招聘 Agent

人力资源招聘 Agent 可以自动筛选简历、安排面试，并为候选人提供个性化的招聘体验，从而提高招聘效率和质量。

10. 员工培训 Agent

员工培训 Agent 可以根据员工的技能和经验，推荐合适的培训课程，并跟踪员工的学习进度，从而提升员工技能和工作效率。

微软的 Agent 战略

微软认为，Agent 是 AI 驱动型业务流程的核心，并将继续投入研发，为 Agent 赋予更强大的功能，帮助企业在 AI 时代保持竞争优势。微软的 Agent 战略主要体现在以下几个方面：

  1. 1. 打造 Copilot Studio 作为 Agent 创建和管理的统一平台: 微软将持续改进 Copilot Studio 的功能，使其更易于使用，并支持更广泛的应用场景。

  2. 2. 推出更多 Dynamics 365 自主 Agent: 微软计划在未来推出更多 Dynamics 365 自主 Agent，覆盖更多业务领域，为企业提供更全面的 AI 支持。

  3. 3. 构建开放的 Agent 生态系统: 微软将与合作伙伴一起，构建开放的 Agent 生态系统，鼓励开发者创建更多 Agent 应用，丰富 Agent 的功能和应用场景。

  4. 4. 推动负责任 AI 的发展: 微软将继续坚持负责任 AI 原则，确保 Agent 的开发和应用符合道德和法律规范，并致力于解决 AI 偏见等问题。

Agent 的未来展望

随着 Agent 在企业中的普及，Copilot 将成为 AI 的新用户界面，Agent 将在 Copilot 的支持下，使工作流程更加智能化和灵活化。Agent 不仅可以帮助企业提高效率，还可以帮助企业创造新的商业模式和价值。例如，Agent 可以帮助企业实现个性化营销、自动化客户服务、优化供应链等。
