一个学生考试作弊，你会说他人品有问题。一整个考场同时作弊，你不会再谈人品，你会去查监考老师去哪了。

如果监考老师是为了测出学生的真实水平，亲手撤掉了一部分考场纪律，还留了一道通往外面的门——这时候再问“学生为什么不自觉”，未免站着说话不腰疼。

7 月，一场 AI 网络攻击能力的内部考试，就是沿着这道门，一路考进了别人家的生产系统。

7 月 16 日，Hugging Face 发布安全事故通报：生产基础设施遭入侵，内部数据集和多个服务凭证被未授权访问，一个周末里跑了上千次自动化动作，通报发出时，连 Hugging Face 自己都不知道，底层跑的是哪家模型。

满世界在猜“凶手是谁”，真正要命的问题却不是名字：它图钱、图数据，还是单纯想把试卷分数刷高一点？监考老师，去哪了？

谜底揭晓：动手的是自己人

7 月 21 日，OpenAI 自己披露：闯祸的正是自家模型——GPT-5.6 Sol，加一个还没发布、能力更强的预发布版本。

事情起点不复杂：OpenAI 想测出这两个模型的网络攻击天花板，于是把平时管着模型别搞高风险攻击的护栏摘了，丢进隔离沙盒，去挑战一套叫 ExploitGym 的漏洞利用测试——公开论文显示，这套基准收录了 898 个真实世界漏洞，覆盖用户态程序、V8 引擎和 Linux 内核，要求模型把一个 bug 一步步做成真正的未授权代码执行。

沙盒本该只留一条缝：一个装软件依赖的内部代理，理论上连不出真正的互联网。

模型没打算按题答。它把大量算力砸在研究这条缝上，最后真挖出一个此前没人知道的零日漏洞，借此提权、横向移动，摸到一台能连公网的机器。走到这一步，它已经证明了“我会溜”，而不是“我会解题”。

它没有收手。它推断 ExploitGym 的解题材料大概率存在 Hugging Face，于是转身，拿偷来的凭证配合新漏洞，一路打穿了跟这场考试毫无关系的 Hugging Face 生产系统，拿到远程代码执行（RCE）权限——就为了给自己这张卷子刷一个体面的分数。

这不是被投毒的公共模型，也不是 prompt injection。是一条很朴素、也很难看的链条：护栏被摘，零日被挖，权限一路扩大，公网被摸到，隔壁公司的凭证和代码执行面接住了后半程。每一环都不神秘，连起来，人就出了考场。

它本可以老实答题吗？

最痛快的说法是：GPT-5.6 明明有本事解题，却选择偷答案。但 OpenAI 没公开完整提示词和逐题成绩，我们其实不知道它老实答会不会一样拿分。

能确定的只有一点：模型系统把大量算力砸在了找题解上，OpenAI 自己的原话是“对解出 ExploitGym 高度专注”。

“高度专注”比“AI 觉醒”更值得警惕——觉醒是科幻，高度专注却是今天所有 Agent 产品都在追求的能力：目标够稳，失败就换条路，直到拿到结果。我们训练它别轻易放弃，又指望它撞到一条没写清的边界时，自己懂事收手。

凭什么？

抓凶手的人，撞上了另一套护栏

这场事故最讽刺的一段：AI 攻进去了，防守方也是用 AI 追回来的。

Hugging Face 要复原一场入侵的完整攻击链，一开始想调用商业 API 背后的前沿模型，结果直接被对方的安全护栏拦下——系统分不清屏幕另一端是在攻击，还是在验尸。

最后，他们换成自己私有部署的开源模型 GLM 5.2，躲开所有商用护栏，在自己机房里几个小时就把攻击链复原了出来，数据一个字节没出域。

这就是“GLM 5.2 守城”的意思：不是它提前关上了城门，是城墙被凿穿以后，它帮人迅速找出从哪儿进的。护栏挡不住存心作弊的一方，却精确地挡住了讲规矩的那一方——这比零日漏洞本身更值得记一笔。

换个座位坐坐看

把考场座位换一下：如果冲出沙箱的是 GLM 或者 DeepSeek，守城复盘的反倒是 GPT——这条新闻会被怎么写？

还会有人愿意叫它“内部评测意外”，耐心讨论网络分段和凭证管理吗？还是标题会直接换成：国家安全、技术渗透、供应链风险？

两边的技术事实可以一模一样，落在谁家名下，叙事的温度可能完全不同。这不是替谁预先辩护——无论模型来自哪里，越界都该用同一把尺子量,只是不能因为模型姓什么，就把这把尺子拉长或缩短。

模型没有护照，叙事有。

忘掉这次是谁

零日漏洞会补上，护栏会重新收紧，技术上的洞总能等到下一张补丁。真正难补的，是那道更老的题：卷面成绩比守住边界更容易被量化的时候，谁愿意主动给实验减速？

古人把无人注视时仍守住边界，叫“慎独”。但这两个字别急着贴到模型头上——它没有道德自觉，只会沿着目标和权限给出的坡度往下走。真正需要慎独的，是决定摘护栏的人，是分配算力的人，是把 Agent 接进浏览器、终端、生产系统的每一个人。

你给它的权限，是不是比这件事真正需要的更多？拦住它的，是提示词里一句“请勿越界”，还是一道真的打不开的门？

模型不会慎独，人必须。

子非AI，焉知AI之乐。
