TLDR

  • • 本文从几何角度揭示了大型语言模型 (LLM) 推理能力提升的关键：自注意力图密度。

  • • 研究发现，提高自注意力图密度可以增加模型表达能力，进而增强推理性能，而无需依赖更大的模型规模。

  • • 文章还阐述了深度神经网络 (DNN) 逼近能力与其输入空间内在维度的关系，为提升模型性能提供了新思路。

引言

大型语言模型（LLM）如 GPT-4 和 Llama 3，在各种任务中都展现出了惊人的能力。然而，提升 LLM 的推理能力仍然是当前研究的重点和难点。现有的改进方法主要集中在增加模型规模和上下文长度上，虽然有效，但也带来了计算成本和推理延迟的增加。

一篇题为 "Reasoning in Large Language Models: A Geometric Perspective" 的论文提出了一种全新的视角，通过几何理解来探索 LLM 的推理能力。作者认为，LLM 的表达能力与其自注意力图的密度密切相关，并通过理论分析和实验证明了这一点。

DNN 的输入空间划分与表达能力

为了更好地理解论文的核心观点，首先需要了解 DNN 的输入空间划分和表达能力之间的关系。

2.1 深度神经网络

DNN 之所以能够逼近各种复杂函数，是因为它能够将输入空间划分为多个区域，并为每个区域学习一个仿射映射。这种连续分段仿射的方式使得 DNN 能够以更精细的粒度来表示目标函数。

如下图所示，一个简单的单隐藏层 MLP 就能够将二维输入空间划分为多个区域。

图1：MLP 的连续分段仿射视图。由随机初始化的单隐藏层 MLP 诱导的输入空间分区

DNN 的逼近能力与其区域数量密切相关。区域数量越多，意味着 DNN 能够以更精细的方式对输入空间进行划分，从而更好地逼近复杂的非线性函数，如下图所示。

图2：DNN 逼近和诱导的输入空间区域数量。MLP 对正弦函数的真实值和逼近值（顶部），MLP 在其输入空间中诱导的相关区域数量（中间）以及逼近误差（底部）。

2.2 大型语言模型: 从自注意力图看表达能力

论文作者将上述关于 DNN 的几何理解扩展到了 LLM，并提出了一个核心观点：LLM 的自注意力图密度决定了 MLP 块输入的内在维度，进而影响 LLM 的表达能力。

2.2.1 自注意力机制与内在维度

自注意力机制是 Transformer 模型的核心组件，它能够捕捉输入序列中不同位置之间的依赖关系。自注意力机制的输出是一个矩阵，表示每个位置与其他所有位置之间的注意力权重。论文作者将这个矩阵视为一个图，其中节点表示输入序列中的标记，边表示标记之间的注意力权重，并将其称为自注意力图。

论文指出，自注意力图的密度（即节点之间连接的密集程度）与 MLP 块输入的内在维度密切相关。内在维度指的是表示数据所需的最小维度数量。自注意力图的密度越高，意味着 MLP 块输入的内在维度越高，这将使得 LLM 能够学习更复杂的函数，进而增强其表达能力。

2.2.2 提升自注意力图密度的途径

为了提高自注意力图的密度，作者提出了两种方法：

  1. 1. 增加注意力头的数量: 每个注意力头可以关注输入序列的不同方面，因此增加注意力头的数量可以捕捉更多样化的依赖关系，从而生成更密集、更全面的自注意力图。

  2. 2. 增加上下文长度: 更长的上下文信息可以提供更丰富的语义信息，帮助模型更好地理解当前输入，从而生成更准确、更细粒度的自注意力图。


图5：LLM 输入空间区域 - （左图）MLP 块在 LLM 输入空间中诱导的区域数量与注意力头数量和上下文长度的关系图。（右图）放大左图的两行，特别是针对多个注意力头：5、10。

2.2.3 几何视角下的表达能力提升

从几何角度来看，增加注意力头数量和上下文长度可以被理解为将 LLM 的输入空间映射到更高维的空间中。这种高维空间能够容纳更多更精细的区域划分，使得 MLP 能够更精准地逼近目标函数，如下图所示。

实验：表达能力与推理能力的相关性

为了验证提高 LLM 表达能力与提升其推理能力之间的关联性，论文作者设计了一系列实验，主要探究增加上下文信息对模型推理能力的影响。

3.1 实验设置

  • • 数据集: 实验使用 GSM8K-Zero 数据集，该数据集包含大量的数学推理问题，适合用来评估模型的推理能力。

  • • 模型: 实验采用了不同规模的 Llama 3 模型，包括 8B 和 70B 等参数规模的模型。

  • • 评估指标: 实验使用正确响应率作为评估指标，即模型成功回答问题的比例。

3.2 实验结果

实验结果如下图所示，展示了不同模型在不同 few-shot 场景下，添加上下文信息与正确响应率之间的关系。


图6：推理与 ID 增加。Llama3 8B（左）和 70B（右）Instruct 模型的正确响应百分比（即推理或提取）与相对 ID 变化的关系。

3.3 结果分析

从实验结果可以看出：

  1. 1. 添加与问题相关的上下文信息可以有效提升 LLM 的推理能力: 无论模型规模大小，在 few-shot 场景下，添加上下文信息都能够显著提高模型的正确响应率。

  2. 2. 上下文信息带来的性能提升在模型规模较小时更加明显: 对于参数规模较小的模型，添加上下文信息带来的性能提升更为显著，这表明，在模型规模受限的情况下，通过增加上下文信息来提升推理能力是一种更有效的途径。

讨论与展望

这篇论文为我们理解 LLM 的推理能力提供了一个全新的几何视角。作者提出的“自注意力图密度决定表达能力”的观点，为提升 LLM 的推理性能提供了一种新的思路。

未来，我们可以进一步探索更有效的方法来提高自注意力图的密度，例如设计新的注意力机制、优化训练策略等。此外，还可以研究自注意力图密度与 LLM 泛化能力之间的关系，为构建更强大、更通用的 LLM 提供理论指导。
