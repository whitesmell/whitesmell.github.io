开源之光！Mora 多智能体框架挑战视频生成霸主 Sora

引言：AI 视频生成领域的革命与挑战

生成式 AI 浪潮席卷全球，以 ChatGPT 为代表的 AI 技术正在以前所未有的速度和深度改变着人类的创作方式。文本生成图像技术已经日臻成熟，Midjourney、Stable Diffusion 等工具将 AI 的艺术创作能力提升到了全新高度。然而，视频生成领域的发展却相对滞后，能够生成高质量长视频的模型更是凤毛麟角，成为生成式 AI 技术中最具挑战性的领域之一。

2024 年 2 月，OpenAI 公司发布了震撼世界的文本到视频生成模型 Sora，它能够将文字描述转化为长达一分钟的高质量视频，其强大的功能和惊人的效果在全球范围内引发了巨大轰动，标志着视频生成领域进入了一个全新的时代。Sora 的出现彻底颠覆了人们对视频创作的认知，为影视、游戏、广告等行业带来了无限可能。

    然而，Sora 采用了封闭的代码库，犹如一座巍峨的城堡，将学术界拒之门外。研究人员无法一窥其内部结构，更无法在其基础上进行改进和创新。此外，运行 Sora 还需要巨大的算力和海量的训练数据，这使得许多研究机构望而却步，只能对 Sora 强大的功能望洋兴叹。

    为了打破 OpenAI Sora 的垄断，让视频生成技术不再是少数巨头公司的专属游戏，来自 Lehigh 大学和微软的研究团队联合开发了一种名为 Mora 的开源多智能体视频生成框架。Mora 不仅在性能上可以与 Sora 相媲美，更重要的是，它采用了开源的方式，将代码和模型公开，让更多人能够参与到视频生成技术的研发中来，共同推动这一领域的发展。Mora 就像是一道耀眼的开源之光，为视频生成技术的未来带来了新的希望。

    Mora：多智能体协同，开启视频生成新纪元

    Mora 的设计理念是模块化和多智能体协作，它将复杂的视频生成任务分解成多个子任务，每个子任务由一个专门的 AI 智能体负责，例如文本到图像生成、图像到图像生成、图像到视频生成、视频连接等。这些智能体就像是一个个技艺精湛的工匠，在 Mora 的指挥下协同工作，共同完成视频生成的“艺术品”。

    Mora 的多智能体架构

    五大核心智能体：

    1. 1. 提示选择和生成智能体： 犹如经验丰富的编剧，负责分析和优化用户提供的文本提示，使其更详细、更易于理解。例如，它可以使用 GPT-4、Llama 等大型语言模型将“一只猫在草地上奔跑”扩展为“一只毛茸茸的橘猫，在一个阳光明媚的午后，欢快地在绿油油的草地上奔跑”。

    2. 2. 文本到图像生成智能体: 犹如技艺精湛的画家，负责将文本提示转化为高质量的初始图像。它可以使用 Stable Diffusion XL (SDXL) 等先进的文图生成模型，根据“一只毛茸茸的橘猫，在一个阳光明媚的午后，欢快地在绿油油的草地上奔跑”的提示生成一只橘猫在草地上奔跑的图像。

    3. 3. 图像到图像生成智能体: 犹如技艺高超的修图师，负责根据文本指令对给定的图像进行编辑和修改。它可以使用 InstructPix2Pix 模型根据文本指令修改图像，例如将生成的橘猫图像替换为用户提供的宠物狗图像。

    4. 4. 图像到视频生成智能体: 犹如富有创造力的导演，负责将生成的图像序列转换为流畅的视频。它可以使用 Stable Video Diffusion (SVD) 模型，为宠物狗图像添加奔跑的动画效果，并生成一段 5 秒钟的视频。

    5. 5. 视频连接智能体: 犹如经验丰富的剪辑师，负责将两个视频片段无缝连接起来。它可以使用 SEINE 模型连接视频，例如将一段宠物狗奔跑的视频和一段宠物狗玩耍的视频连接起来。

    六大核心功能:

    通过多个智能体之间的协同工作，Mora 目前支持六种视频生成任务：

    1. 1. 文本到视频生成:
      根据详细的文本提示生成视频。

    2. 2. 文本引导的图像到视频生成:
      根据文本提示和初始图像生成视频。

    3. 3. 扩展生成视频:
      将现有视频扩展为更长的视频。

    4. 4. 视频到视频编辑:
      根据文本指令编辑现有视频。

    5. 5. 连接视频:
      将两个独立的视频片段无缝连接起来。

    6. 6. 模拟数字世界:
      生成具有数字世界风格的视频，例如模拟游戏场景。

    Mora 与 Sora 的巅峰对决：性能大比拼

    为了评估 Mora 的性能，研究人员使用公开的视频生成基准 Vbench 以及自定义指标对 Mora 和 Sora 在六项任务上的表现进行了对比测试。

    3.1 基准测试：Vbech 和自定义指标

    Vbech 是一个用于评估视频生成模型的综合基准测试集，包含多个指标，例如视频质量、视频-文本一致性、时间一致性等。研究人员还根据具体任务设计了一些自定义指标，例如视频长度、画面清晰度等。

      深入解析 Mora Demo 代码：初探多智能体视频生成技术

      为了帮助开发者更好地理解 Mora 的工作原理，Lehigh 大学和微软的研究团队提供了一个简单的 Demo 代码，展示了如何使用 Stable Diffusion 和 Stable Video Diffusion 模型来完成一个基本的视频生成任务：根据文字提示“一个男孩”生成一段包含三个片段的短视频。这个 Demo 代码模拟了 Mora 的部分工作流程，让我们来一步一步地解析这段代码，揭开多智能体视频生成技术的神秘面纱。

      第一步：文本生成图像，Stable Diffusion XL 构建初始画面

      from diffusers import DiffusionPipeline
      import torch

      # 加载 Stable Diffusion XL 模型的 base 和 refiner 部分
      base = DiffusionPipeline.from_pretrained(
          "stabilityai/stable-diffusion-xl-base-1.0", torch_dtype=torch.float16, variant="fp16", use_safetensors=True
      )
      base.to("cuda")
      refiner = DiffusionPipeline.from_pretrained(
          "stabilityai/stable-diffusion-xl-refiner-1.0",
          text_encoder_2=base.text_encoder_2,
          vae=base.vae,
          torch_dtype=torch.float16,
          use_safetensors=True,
          variant="fp16",
      )
      refiner.to("cuda")

      # 定义 Stable Diffusion 模型的推理步骤和噪声调度参数
      n_steps = 40
      high_noise_frac = 0.8

      def Get_image(prompt):
          # 使用 base 模型生成带有噪声的初始图像
          image = base(
              prompt=prompt,
              num_inference_steps=n_steps,
              denoising_end=high_noise_frac,
              height=576,
              width=1024,
              output_type="latent",
          ).images

          # 使用 refiner 模型对初始图像进行优化
          image = refiner(
              prompt=prompt,
              num_inference_steps=n_steps,
              denoising_start=high_noise_frac,
              height=576,
              width=1024,
              image=image,
          ).images[0]

          # 保存生成的图像为 image.png 文件
          image.save('image.png')
          return image

      这部分代码首先加载了 Stable Diffusion XL 模型的两个部分：base 和 refiner。base 模型负责根据文本提示生成初始图像，refiner 模型负责对初始图像进行优化，使其更加清晰和逼真。这两个模型的协同工作，就相当于 Mora 中的 文本到图像生成智能体。

      代码中还定义了 Stable Diffusion 模型的推理步骤数量 n_steps 和噪声调度参数 high_noise_frac。Get_image 函数则封装了使用 Stable Diffusion XL 模型生成图像的过程，它接受一个文本提示作为输入，并输出生成的图像。

      第二步：图像生成视频，Stable Video Diffusion 赋予画面生命

      import torch

      from diffusers import StableVideoDiffusionPipeline
      from diffusers.utils import load_image, export_to_video

      # 加载 Stable Video Diffusion 模型
      pipe = StableVideoDiffusionPipeline.from_pretrained(
        "stabilityai/stable-video-diffusion-img2vid-xt", torch_dtype=torch.float16, variant="fp16"
      )
      pipe.enable_model_cpu_offload()

      import time
      from moviepy.editor import VideoFileClip, concatenate_videoclips
      from PIL import Image

      def generate_and_concatenate_videos(initial_image_path, num_iterations=60):
          video_paths = []  # 用于存储生成的视频片段路径
          current_image_path = initial_image_path

          # 循环迭代生成多个视频片段
          for iteration in range(num_iterations):
              # 加载当前图像
              image = Image.open(current_image_path).resize((1024, 576))

              # 设置随机种子
              seed = int(time.time())
              torch.manual_seed(seed)

              # 使用 Stable Video Diffusion 模型生成一组新的帧
              frames = pipe(image, decode_chunk_size=12, generator=torch.Generator(), motion_bucket_id=127).frames[0]

              # 将生成的帧保存为视频片段
              video_path = f"video_segment_{iteration}.mp4"
              export_to_video(frames, video_path, fps=25)
              video_paths.append(video_path)

              # 获取当前视频片段的最后一帧作为下一轮迭代的初始图像
              current_image_path = Get_Last_Frame(video_path, "1.png")

          # 将所有视频片段拼接成一个完整的视频
          clips = [VideoFileClip(path) for path in video_paths]
          final_clip = concatenate_videoclips(clips)

          # 保存完整的视频
          final_clip.write_videofile("final_output_video.mp4")

      def Get_Last_Frame(video_path, output_image_path):
          # 使用 moviepy 加载视频
          from moviepy.editor import VideoFileClip
          with VideoFileClip(video_path) as video:
              # 获取视频的最后一帧
              last_frame = video.get_frame(video.duration - 0.01)  # 获取视频结束前 0.01 秒的帧

          # 将最后一帧保存为图像
          from PIL import Image
          last_frame_image = Image.fromarray(last_frame)
          last_frame_image.save(output_image_path)
          return last_frame_image

      这部分代码加载了 Stable Video Diffusion 模型，并定义了 generate_and_concatenate_videos 和 Get_Last_Frame 两个函数。generate_and_concatenate_videos 函数负责使用 Stable Video Diffusion 模型将一系列图像转换为视频片段，并最终拼接成一个完整的视频。Get_Last_Frame 函数则负责从视频片段中提取最后一帧图像，为下一段视频片段的生成提供初始画面。

      Stable Video Diffusion 模型相当于 Mora 中的 图像到视频生成智能体，它能够根据初始图像生成后续帧，并使画面动起来，形成视频。

      第三步：调用函数，生成“一个男孩”的视频

      # 生成初始图像
      Get_image("A boy")

      # 生成视频
      generate_and_concatenate_videos("image.png", 3)

      最后，这段代码调用 Get_image 函数根据提示“A boy”生成一个名为 "image.png" 的图像，作为初始画面。然后，调用 generate_and_concatenate_videos 函数，使用 "image.png" 作为初始图像，生成一个包含三个片段的视频。

      Demo 代码展示了 Mora 多智能体协同工作的基本流程：首先，文本到图像生成智能体根据文本提示生成初始图像；然后，图像到视频生成智能体根据初始图像生成后续帧，并拼接成视频片段；最后，将多个视频片段拼接成一个完整的视频。

      这个 Demo 代码仅仅展示了 Mora 强大功能的冰山一角。随着技术的不断发展，相信 Mora 会给我们带来更多惊喜，彻底颠覆视频创作的方式，让每个人都能够成为视频制作大师!
